What the examples prove

The demos are more than screenshots. They are complete, working pages built with the same stylesheet you ship.

Real components

Every screen is assembled from the framework grid, cards, buttons, forms, tables, navs, badges, and avatars.

Token driven

Company, studio, and dashboard lean on the same color, surface, border, and radius variables. The newer developer platform, storefront, and bistro examples are styled almost entirely by overriding them.

Standalone by design

Each demo is a plain HTML, CSS, and JS folder with no build step, no framework runtime, and no dependency beyond roolith.
