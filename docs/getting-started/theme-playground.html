Shipping a smaller stylesheet Notes from the 4.0 build review

Every module is opt-in at the Sass layer. A page that only needs typography and buttons can leave the rest of the modules out of the entry point.

Start with the base layer, then add one module at a time and check the compiled size after each step. The token layer is shared, so removing a module rarely leaves unused custom properties behind.

  • Keep the base layer and the token layer in every build.
  • Load modules in the same order as the entry point to keep the cascade predictable.
  • Re-measure after adding an extended module, because those carry the most rules.
