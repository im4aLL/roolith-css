Typography

Element defaults cover the common cases, and a small set of utility classes covers the rest. Headings step up at 1024px, body copy sits on a 14px to 22px rhythm, and list, alignment, and emphasis helpers are one class each.

class: Multiple elements and classes - defined in _typography.scss
_reset.scss zeroes the margins of body, headings, paragraphs, lists, and blockquotes with :where(). Spacing is then yours to add, and any consumer rule wins over the reset.

Base text

html takes its font size from --r-global-base-font-size, which is $base-font-size: 100% by default. That keeps the browser default instead of forcing a pixel size, so rem values follow the reader's zoom.

Body copy is set by the p element at rem(14) with a rem(22) line height. strong uses the bold weight token, em is italic, u underlines, abbr gets a dotted underline and a help cursor.

Body copy sits at 14px with a 22px line height. Strong uses the bold weight token, emphasis is italic, and underline adds a rule.

Abbreviations such as CSS get a dotted underline and a help cursor.

Headings

Every heading level steps up once at 1024px, which keeps the small screen scale compact without a fluid clamp. Tracking follows the rendered size rather than the level: it tightens to -0.03em from 24px and to -0.04em from 40px.

The .h1 through .h6 classes apply the same size and weight to any element, which is how you keep a visual hierarchy that does not match the document outline. The demo below uses div elements with those classes, so this page keeps its single h1.

Links

A link takes var(--r-link) and moves to var(--r-accent) on hover. Underlines are applied inside prose containers - p, blockquote, dl, .list, .list-numbered, .comment-body, label, and .message - so a link in body copy is not signaled by color alone.

Because the rule lists prose containers rather than components, a link inside .nav, .tag, or .avatar keeps its own styling; only an anchor that declares text-decoration itself, such as .button, opts out.

A link inside body copy, like the layout guide, carries an underline.

A standalone link is not underlined; hover changes only its color.

Lists

The reset removes list markers and padding. .list restores disc markers and .list-numbered restores decimals on the same base: 14px copy, 22px line height, 25px of vertical padding, a 15px left margin, and a 10px gap under each item. Nested lists indent by 30px.

Small and dimmed text

small and .small drop to 80% size with a 1.3em line height. .dimmed lowers opacity to 0.6 instead, which keeps the font size and only reduces emphasis.

Alignment and floats

Three text classes and two float classes cover the common cases. .full-width sets width: 100% for a block that should ignore its content width. A floated element needs a clearfix parent, and roolith css ships .clearfix for that.

Code and pre

code is an inline chip: monospace, 90% size, a muted surface, and a hairline border. The framework keeps inline code on one line with white-space: nowrap, and this docs site lets inline code wrap so a long token does not widen the page. Only block code inside pre renders the thin themed scrollbar; an inline copy wraps instead of scrolling.

Inside pre the same element switches to a block with rem(15) of padding, a 14px size, the code background token, and 20px below it. kbd reuses the inline style with a solid muted surface to read as a key cap.

Use grid-column-end when a span needs to be set in CSS.

);

Blockquote and horizontal rule

blockquote leads with a 3px muted border and 20px of padding. A cite inside it drops to 80% and moves to its own line, prefixed so the attribution is not signaled by position alone.

hr is a 1px two tone rule with 15px above and below, which reads as a groove on both light and dark surfaces.

Accessibility

Typography classes change how text looks, not what it means, so the document outline and the plain text settings still decide how the page reads.

  • Keep one h1 per page and do not skip levels. The .h1 through .h6 utilities are a visual size only, so a heading that looks smaller is still an h2 or h3 in the markup.
  • Keep body line length readable. The framework sets font size and line height but no measure, so cap a prose column with your own max-width instead of letting text run the full width of a wide screen.
  • Do not use .dimmed as the only way to convey important information. It lowers opacity to 0.6, which reduces contrast below the readable range for small copy.
  • Make a link distinguishable by more than color. The framework underlines links inside prose containers; a link that stands alone has no underline, so add one (or another non-color cue) yourself.
  • Use real list markup rather than visual bullets. .list and .list-numbered style ul and ol, and a screen reader announces the item count only when the list element is real.
  • Respect the user font-size setting. Sizes are written in rem against $base-font-size: 100%, so a reader who raises the browser font size gets larger text, and a hardcoded pixel size in your own CSS cancels that.

Class reference

Elements carry the defaults. These classes extend or override them without adding markup.

Class Applies Notes
.h1 Heading size Also .h2 through .h6. Same size and weight as the element, no outline change.
.small Size 80% of the inherited size with a 1.3em line height.
.dimmed Emphasis Opacity 0.6 at the inherited size.
.list List Disc markers on the 14px to 22px base with 25px vertical padding, a 15px left margin, and a 10px gap under each item.
.list-numbered List Decimal markers on the same base.
.indented-list Definition list Indents every dd by 30px. Set it on the dl.
.text-left Alignment Text align. Also .text-center and .text-right.
.float-left Float Also .float-right. Needs a .clearfix parent.
.full-width Width width: 100% on the element.
