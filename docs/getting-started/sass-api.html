Sass API

roolith css is a set of Sass modules. Settings live in their own module, so you configure the build with a @use ... with block before you load the entry, and the same functions and mixins that build the framework are available to your own components.

class: Multiple mixins and functions - defined in roolith.scss, _settings.scss, functions/, mixins/
The examples use paths your bundler resolves from the installed package: roolith-css/src/sass/roolith.scss for the complete stylesheet and roolith-css/src/sass/main when you want to include only some groups. Adjust the prefix if you load the source from somewhere else.

Entry point

src/sass/roolith.scss is the install entry. It loads ./main and runs roolith-everything() at the end, so one @use emits the complete stylesheet.

src/sass/main.scss is the library behind that entry. It declares the mixins that emit each group of styles and writes no rules: only the mixins you include produce output, which is what makes selective builds possible. Neither file declares a variable, so overrides go to settings, which you load with a with block before either one.

  • _main.scss declares the group mixins; roolith.scss includes all of them.
  • _settings.scss holds every configurable variable, all with !default.
  • _css-var.scss turns those settings into the --r-* custom properties.
  • _reset.scss, _base.scss, and _typography.scss cover element defaults.
  • _state.scss adds the show, hide, and state helpers.
  • modules/ and blocks/ hold one partial per component, each exposing a mixin.
  • functions/ and mixins/ are the shared toolkit the modules are built on.

Configuration

Load the settings module with a with block before the file that reads it. The configuration is applied on that first load, so keep it in one place and keep it first.

An override replaces the default rather than merging into it, so a map such as $colors has to be passed complete. Keep $colors , $colors-on , and $colors-text in step as well: a palette name without a text recipe stops the build inside text-token().

SCSS 
@use 'roolith-css/src/sass/settings' with (
    $base-font-family: ('Inter', sans-serif),
    $container-width: 90rem,
    $grid-gutter-size: 1.5rem,
    $border-radius: 0.5rem,
    $primary-color: #2f6feb,
    $animation-duration: 0.2s
);
@use 'roolith-css/src/sass/roolith';

Global settings

Variable Default Notes
$base-font-size 100% Root font size, exposed as --r-global-base-font-size.
$base-font-family 'Inter', sans-serif Body font family, exposed as --r-global-base-font.
$global-font-weight normal Body weight.
$global-font-bold-weight 600 Headings, strong, and definition terms.
$border-radius rem(8) Exposed as --r-global-border-radius.

Breakpoints

Variable Default Notes
$breakpoints small: 0, medium: 640px, large: 1024px, xlarge: 1200px, xxlarge: 1440px Drives the breakpoint mixin, the grid prefixes, and the show and hide helpers. Keys are read by name, so keep all five.

Grid

Variable Default Notes
$container-width rem(1200) Exposed as --r-global-width and used by .container.
$grid-gutter-size rem(20) Single gutter value used to build the gutter map.
$grid-gutter small, medium, large Per breakpoint gutter map. Override it for a different rhythm per size.
$grid-column-count 12 Track count for the grid and the span, offset, push, and pull loops.
$grid-layout css-grid Or traditional for the legacy float grid. Any other value stops the build with an error.

Colors

Variable Default Notes
$primary-color #4a5cd0 One variable per palette name: primary, secondary, tertiary, info, success, warning, danger, link, dark, black, white, light. Each becomes --r-color-<name>.
$theme-dark-color #0c0c0c Base neutral for the dark theme.
$colors Palette map Drives every color and background utility, and every component that loops the palette.
$colors-on Palette map Foreground color for each palette fill.
$colors-text Palette map Text recipe per palette name for light surfaces.
$colors-dark Partial map Color overrides in dark mode. Only the listed names change.
$colors-text-dark Palette map Text recipes in dark mode.

Animation and other

Variable Default Notes
$animation-easing cubic-bezier(1, 0, 0, 1) Exposed as --r-animation-easing.
$animation-duration 0.25s Exposed as --r-animation-duration.
$modal-layout css-grid Or traditional for the legacy block internals, or flex to center the content with flexbox. Selects the grid, block, or flex internals of the modal.
$spacer 5, 10, 15 ... 250 Pixel list that generates the .spacer-N classes.
$block-padding rem(20) Exposed as --r-block-padding for the block partials.

Selective builds

The framework groups its output into six mixins, and roolith-everything() calls all of them. Each group is a plain list of includes in src/sass/_main.scss , so you can see exactly what it emits.

Mixin Emits
roolith-base() The custom properties, the reset, the base element styles, typography, and the color utilities.
roolith-modules() The core components: animation, button, nav, form, table, img, message, badge, breadcrumb, card, dropdown, modal, stat, accordion, tab, box, article, progress, collage, avatar, tag, page, comment, toast notification, and icon.
roolith-extended-modules() The higher level components: form extended, tooltip, popover, drawer, combo box, action menu, pagination, spacer, indicator, quick menu, sidebar nav, and datepicker.
roolith-blocks() Every composed page block in blocks/ , from the header and auth screens to the stat table and SVG map.
roolith-layout() The grid selected by $grid-layout , then the application layout scaffold.
roolith-state() The show and hide helpers, .clearfix, and the .is-* state classes.
roolith-everything() All six above, in that order: base, modules, extended modules, blocks, layout, state.

roolith-layout() prints a warning when $grid-layout is traditional and raises an error for any other value, so a typo cannot quietly produce a stylesheet without a grid.

Loading the entry file emits everything, so a smaller bundle means loading main and calling only the groups you need. It writes nothing on its own. To override a setting, load settings with a with block first; the entry file reads the same module when you use it instead.

SCSS 
@use 'roolith-css/src/sass/main' as r;

@include r.roolith-base();
@include r.roolith-modules();
@include r.roolith-extended-modules();
@include r.roolith-blocks();
@include r.roolith-layout();
@include r.roolith-state();

Functions

Functions live in src/sass/functions . Load them with a wildcard namespace when you want the short names, or a named one to keep the call sites explicit.

Signature Returns
rem($pixels, $context: 16px) A rem value. Unitless input is treated as pixels; the context divides it.
color-lighten($color, $amount) A color-mix with white at the given amount.
color-darken($color, $amount) A color-mix with black at the given amount.
str-replace($string, $search, $replace: '') The string with every match replaced. The replacement defaults to empty.
url-encode($string) The string with URL reserved characters percent encoded.
inline-svg($string) A url() with the encoded SVG as a utf8 data URI.
palette-fill($name) var(--r-color-<name>).
palette-on($name) var(--r-color-<name>-on), the foreground for that fill.
palette-text($name) var(--r-color-<name>-text), the readable text tone.
text-token($name, $recipes, $ink) A color-mix of the palette color and the ink, or the raw variable when the recipe is 0%. Errors when the name has no recipe.
heading-tracking($size) -0.02em below 24, -0.03em from 24, -0.04em from 40. Ships with the text pattern in mixins/_text-pattern.scss, so load it through the mixins namespace.
SCSS 
@use 'roolith-css/src/sass/functions' as *;

.card-cover {
    width: rem(320);
    padding: rem(20);
    border: rem(1) solid palette-text('primary');
    background-color: palette-fill('primary');
    color: palette-on('primary');
}

.card-cover-link {
    color: color-darken(#4a5cd0, 15%);
}

Mixins

Mixins live in src/sass/mixins . They are the same helpers the framework modules use, so a custom component built on them follows the framework's breakpoints, transitions, and text rhythm without copying values.

Signature Emits
breakpoint($range) A media query for small-only, medium-up, medium-only, large-up, large-only, xlarge-up, xlarge-only, xxlarge-only, or xxlarge-up.
transition($property, $transition-duration: 150ms, $transition-delay: 0s, $transition-method: ease-in-out) Property, duration, timing function, and delay.
abs-pos($top: auto, $right: auto, $bottom: auto, $left: auto) Absolute positioning with the four offsets.
border-radius($radius) Radius plus background-clip: padding-box. Also border-top-radius, border-right-radius, border-bottom-radius, and border-left-radius.
clearfix A table based clearfix on the current selector.
opacity($opacity) Opacity plus the legacy filter fallback.
triangle($direction, $size, $color: currentColor) A border triangle for up, down, left, or right. Any other value is treated as a rotation angle.
image-2x($image, $width, $height) A retina media query with the background image and size.
nice-scroll($trackColor: var(--r-scrollbar-track), $scrollbarColor: var(--r-scrollbar-thumb)) A thin WebKit scrollbar. Defaults to the --r-scrollbar-* tokens.
loader($size: 20) A spinning circle that uses the loading keyframes.
text-truncate Overflow hidden with an ellipsis and no wrapping.
animation($name: null) Visible, with the duration, fill mode, and easing tokens. Pass a name to set the animation.
heading-step($size, $line-height) A heading size and leading in pixels on the framework scale, with matching tracking.
text-small 80% size with a 1.3em line height.
text-dimmed Opacity 0.6.
button-base, button-small Resting, hover, and active button appearance, and the small size.
img-full-width, fig-fit Full width media, and cover cropping for a fixed ratio figure.

A custom component below uses three of them together: rem keeps the spacing on the root scale, breakpoint keeps the media query in step with the grid, and transition keeps the timing consistent with the framework.

SCSS 
@use 'roolith-css/src/sass/functions' as *;
@use 'roolith-css/src/sass/mixins' as *;

.notice-bar {
    padding: rem(12) rem(16);
    border-left: rem(3) solid palette-fill('info');
    background-color: var(--r-surface-muted);
    font-size: rem(14);
    line-height: rem(22);
    @include transition('background-color, border-color');

    @include breakpoint(large-up) {
        padding: rem(16) rem(24);
        font-size: rem(16);
        line-height: rem(24);
    }

    &:hover {
        background-color: var(--r-surface-hover);
        border-left-color: palette-fill('primary');
    }
}

The breakpoint mixin

breakpoint($range) wraps its content in a media query built from $breakpoints , so a custom component answers at the same widths as the grid. Write the base styles on the bare selector, then pass a range name to add the larger sizes inside the query.

Range Emitted query with the default map
small-only @media (max-width: 639px)
medium-up @media (min-width: 640px)
medium-only @media (min-width: 640px) and (max-width: 1023px)
large-up @media (min-width: 1024px)
large-only @media (min-width: 1024px) and (max-width: 1199px)
xlarge-up @media (min-width: 1200px)
xlarge-only @media (min-width: 1200px) and (max-width: 1439px)
xxlarge-only @media (min-width: 1440px)
xxlarge-up @media (min-width: 1440px)

There is no small-up range because small is the base and needs no query. Each -only upper bound comes from the next named width minus one, so xxlarge-only and xxlarge-up are the same query: the map has no wider key. An unknown range name emits nothing, so a typo fails quietly; check the compiled CSS when a breakpoint seems to do nothing.

SCSS 
@use 'roolith-css/src/sass/mixins' as *;

.card-list {
    display: grid;
    grid-template-columns: minmax(0, 1fr);
    gap: 12px;

    @include breakpoint(medium-up) {
        grid-template-columns: repeat(2, minmax(0, 1fr));
    }

    @include breakpoint(large-up) {
        grid-template-columns: repeat(3, minmax(0, 1fr));
    }
}

.sidebar-hint {
    display: none;

    @include breakpoint(medium-only) {
        display: block;
    }
}

Change $breakpoints in the settings with block to move every query at once. The map replaces the default rather than merging into it, so keep all five keys. The grid prefixes, the show and hide helpers, and every component built on the mixin read the same map, which keeps those breakpoints aligned after an override.

Sass settings and CSS variables

A Sass setting is read at build time. The same value is usually emitted as a custom property, which is read at runtime. That split decides where a change belongs.

  • Colors, the container width, the base font, the border radius, the animation values, and the block padding all reach the browser as --r-* tokens, so overriding the custom property is enough.
  • Breakpoints define media queries, the grid layout selects which grid compiles, the gutter and column count are baked into padding and span rules, and the spacer list generates classes. Those need a rebuild.
CSS 
:root,
.theme-dark {
    --r-global-width: 90rem;
    --r-color-primary: #2f6feb;
}

Theme classes redeclare the palette, so scope a runtime override to the theme class you target, or list both scopes as above. Components read the tokens, so a single override reaches every component that uses that role.
