Block list

A block list stacks short rows: settings, summary lines, checklists, and anything else that reads top to bottom. The block supplies the rhythm between rows and an optional divider, and leaves the content of each row to the component you place inside it.

class: .block-list - defined in blocks/_block-list.scss

Basic usage

.block-list is a flex column with no gap of its own. Spacing comes from each .block-list-item, which gets half of --r-block-padding above and below, so a 20px block rhythm gives 10px of padding per edge and 20px between two rows.

The global reset already removes list margins, padding, and markers, so an unstyled <ul> is the right element here: it keeps the list semantics without adding a bullet or indent that the block would have to undo.

.block-list-label sets a row label to 14px. That matches paragraph copy rather than the 16px body size, so the label does not grow when the list sits inside larger text. The class does not bold the text; use a heading or a <strong> when a row needs more emphasis.

  • Workspace
  • Plan
  • Region
  • Seats
HTML 
<ul class="block-list">
    <li class="block-list-item">
        <span class="block-list-label">Workspace</span>
    </li>
    <li class="block-list-item">
        <span class="block-list-label">Plan</span>
    </li>
    <li class="block-list-item">
        <span class="block-list-label">Region</span>
    </li>
    <li class="block-list-item">
        <span class="block-list-label">Seats</span>
    </li>
</ul>

Because the spacing lives on the item, you can drop the padding from one row or add a taller block inside another without breaking the rest of the list. The token --r-block-padding controls every edge at once.

Bordered list

Add .block-list-bordered to the list for a divider between rows. The selector is .block-list-bordered .block-list-item, so the modifier has to sit on the list or on another ancestor, not on each item.

Every item gets a 1px bottom border, and :last-child removes it, so the list never ends with a stray line. The color comes from --r-block-list-item-border-color, which resolves to a step on the muted surface scale, so the divider follows the theme without a separate dark-mode rule.

  • Build 1284 passed
  • Container image pushed
  • Staging deployed
  • Smoke tests passed
HTML 
<ul class="block-list block-list-bordered">
    <li class="block-list-item">
        <span class="block-list-label">Build 1284 passed</span>
    </li>
    <li class="block-list-item">
        <span class="block-list-label">Container image pushed</span>
    </li>
    <li class="block-list-item">
        <span class="block-list-label">Staging deployed</span>
    </li>
    <li class="block-list-item">
        <span class="block-list-label">Smoke tests passed</span>
    </li>
</ul>

The divider sits at the bottom edge of the item padding, so it is 10px below the label and 10px above the next one. Keep that in mind when a row gets its own padding; the two add up.

Label and value rows

The block has no value class. Pair .block-list-label with plain text and place the two ends with your own layout: the block only owns the row padding. A flex row with justify-content: space-between keeps the value at the right edge without a second column.

The demo reuses .block-list-label for the value so both ends share the 14px size. The class sets only the size, so the value is still plain text.

  • Storage used 48.2 GB of 100 GB
  • Bandwidth this month 612 GB
  • Deployment Live
HTML 
<ul class="block-list block-list-bordered">
    <li class="block-list-item">
        <div style="display: flex; justify-content: space-between; gap: 16px">
            <span class="block-list-label">Storage used</span>
            <span class="block-list-label">48.2 GB of 100 GB</span>
        </div>
    </li>
    <li class="block-list-item">
        <div style="display: flex; justify-content: space-between; gap: 16px">
            <span class="block-list-label">Bandwidth this month</span>
            <span class="block-list-label">612 GB</span>
        </div>
    </li>
    <li class="block-list-item">
        <div style="display: flex; justify-content: space-between; align-items: center; gap: 16px">
            <span class="block-list-label">Deployment</span>
            <span class="badge badge-success">Live</span>
        </div>
    </li>
</ul>

Keep values short. The block never truncates or wraps a row for you, so a long value either wraps inside the flex row or pushes the label aside. For a two-column layout with many rows, a table or the stat table block is the better fit.

Actions and controls

Rows are plain block content, so buttons, badges, and form controls drop in without a wrapper. Keep row actions small: .button-small or .button-text keeps the row height predictable, while a full size button stretches every row to its own height.

A checkbox row uses .form-checkbox-label and .form-check-input, the same classes as the form module. The label covers the row content, so a click anywhere on the text toggles the box.

  • Ada Lovelace Owner
  • Grace Hopper Admin
  • Alan Turing Member
HTML 
<ul class="block-list block-list-bordered">
    <li class="block-list-item">
        <div style="display: flex; align-items: center; gap: 10px">
            <span class="block-list-label">Ada Lovelace</span>
            <span class="badge badge-primary">Owner</span>
            <button class="button button-small button-text" type="button" style="margin-left: auto" aria-label="Manage Ada Lovelace">Manage</button>
        </div>
    </li>
    <li class="block-list-item">
        <div style="display: flex; align-items: center; gap: 10px">
            <span class="block-list-label">Grace Hopper</span>
            <span class="badge">Admin</span>
            <button class="button button-small button-text" type="button" style="margin-left: auto" aria-label="Manage Grace Hopper">Manage</button>
        </div>
    </li>
    <li class="block-list-item">
        <div style="display: flex; align-items: center; gap: 10px">
            <span class="block-list-label">Alan Turing</span>
            <span class="badge">Member</span>
            <button class="button button-small button-text" type="button" style="margin-left: auto" aria-label="Manage Alan Turing">Manage</button>
        </div>
    </li>
</ul>

Name every row action after the row it changes, not just "Manage", because a screen reader can list buttons out of context. aria-label="Manage Ada Lovelace" on the button is enough when the visible label has to stay short.

Accessibility

The block is a stack of rows, and the element you choose for each row decides what a screen reader announces.

  • Use <ul> with <li> for a set of rows, as the demos do, so the item count is announced. The reset removes the markers, so the block looks the same.
  • For label and value pairs, prefer <dl> with <dt> and <dd>, which ties each value to its label. Two spans in a flex row read as two unrelated runs of text.
  • Give every row action a name that includes the row, as the demos do with aria-label="Manage Ada Lovelace", because a screen reader can list the buttons out of context.
  • Keep focus visible. The item padding and the divider do not clip the framework :focus-visible ring, so do not add overflow: hidden on a row that holds a control.
  • A badge such as Owner or Live carries meaning, so keep the word in the text and do not reduce the row state to a color alone.

Class reference

The block defines one container, one item, one label, and an ancestor modifier for dividers.

Class Applies Notes
.block-list Wrapper Flex column with no gap; the items carry the spacing.
.block-list-item Item Half of --r-block-padding above and below, 10px per edge at the default 20px rhythm.
.block-list-label Label 14px label text. No weight change and no truncation.
.block-list-bordered Modifier Ancestor modifier. Adds a 1px bottom border to each item from --r-block-list-item-border-color, removed on the last child.
