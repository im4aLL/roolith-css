Block stat

The stat block puts a set of headline metrics next to each other, each with a label, a number, and an optional change marker. It is a layout shell: the item surface stays transparent until it is hovered or marked active, and the type sizes are owned by the block rather than borrowed from a card.

class: .block-stat - defined in blocks/_block-stat.scss

Basic usage

The wrapper is a flex column that becomes a row at 640px. Each .block-stat-item is a two column grid: the label spans both columns, the value takes the left column, and the indicator takes the right column on the same row as the value.

The slots are independent, so an item without a comparison has no indicator element at all. The value keeps the left half of the item and the right half stays empty.

Padding and gaps both come from half of --r-block-stat-item-gap, which defaults to --r-block-padding at 1.25rem, so an item pads 10px on every side and the items sit 10px apart. The item radius is --r-block-stat-item-border-radius, an 8px value by default.

The value is 22px at --r-global-font-bold-weight with -0.02em tracking, and the label is 14px in the inherited text color. The module does not right align the indicator, so a change marker starts at the second column, near the middle of the item, instead of sitting at the right edge.

Indicators

.block-stat-indicator only aligns its slot to the bottom of the value row; the marker itself comes from the indicator utilities, which paint a masked glyph and a color through --r-indicator-upward-color, --r-indicator-downward-color, --r-indicator-flat-color, and --r-indicator-online-color.

Anything after the value lands in the second column, but only the .block-stat-indicator wrapper aligns that content to the bottom of the value row. Keep the wrapper even when the marker is a status dot or a short comparison word rather than a percentage.

Direction is not sentiment. is-upward uses the success color and is-downward the danger color whatever the metric means, so a falling refund rate still reads as red. Say which way is good in the label or in the text next to the marker.

Active and hover

Hovering an item and adding .active produce the same fill, taken from --r-block-stat-item-hover-background-color, plus a pointer cursor. The background transitions over 150ms, so the fill arrives with the pointer instead of snapping on.

.active is a plain class with no script behind it. Set it from your router or from the selection logic that already knows which metric is on screen, and remove it when the selection moves.

The block has no focus style and no keyboard handling, because the item is a plain <div>. When a metric opens a detail view, put the link or the button inside the item so the focus ring and the key handling come from a real control.

The fill defaults to --r-surface-muted, which resolves per theme, so the hint is visible in dark mode without an override. The item surface itself is --r-block-stat-item-background-color and starts transparent.

Responsive row

Below 640px the wrapper stays a column, so each item reads as its own stacked block. From 640px up the same wrapper becomes a row. The docs demo follows the window width, so narrow the window to watch the switch happen.

Items do not grow: each one takes the width of its content. Five short metrics fit on one line at desktop widths, while a long label or value widens its item and can push the row past the container. Keep labels to a couple of words and values compact when a row carries more than four items.

The block stops at the layout. It draws no outer padding, so put it inside a container that owns the spacing, such as a .box body, a card, or the body of an analytics panel. For a single centered number in a card, use the stat component instead: it stacks a header, a value, and a footer, while this block lays out several items in one row.

Accessibility

The block is a set of div elements, so a screen reader reads the label, the value, and the marker as one run of text per item. Nothing about the layout conveys a relationship that the reading order does not already give, which is fine for a strip of summary numbers.

  • Write the value with its unit and its separators, as in $48,290 or 184 ms. Shorthand such as 100k is read as letters and loses the magnitude.
  • The arrow in an indicator is a masked background, so add the direction in words, for example 12.4% up, or keep a comparison phrase such as "vs last month" next to it.
  • When the items form a set that a reader should hear as a group, use a list: <ul class="block-stat"> with <li class="block-stat-item">. The reset already removes the markers and the indent.
  • If an item is clickable, the item itself is not focusable. Put an <a> or a <button> inside it so the control appears in the tab order.
  • .active only changes the background. Give the selected metric a second cue, such as a heading change or aria-current on the link that points at it.

Class reference

Four classes build the block and one token family tunes it. The tokens are --r-block-stat-item-gap, --r-block-stat-item-background-color, --r-block-stat-item-hover-background-color, and --r-block-stat-item-border-radius. The gap token is a single length that the module halves for the outer gap, the item padding, and the item grid gap, so raising it spaces all three together.

Class Applies Notes
.block-stat Wrapper Flex column with a 10px default gap, switching to a row at 640px up.
.block-stat-item Item Two column grid with a 10px gap, 10px padding, an 8px radius, and a transparent background.
.block-stat-item.active Item state Same fill as hover, plus a pointer cursor. The class carries no script and no focus style.
.block-stat-label Item slot 14px label that spans both grid columns.
.block-stat-value Item slot 22px value at --r-global-font-bold-weight with -0.02em letter spacing.
.block-stat-indicator Item slot Right column of the value row, aligned to the bottom. Place an .indicator inside it.
.indicator Composition Inline change marker from the utilities module. Modifiers: is-upward, is-downward, is-flat, is-online.
