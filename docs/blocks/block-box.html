Block box

A block box is a compact metric tile: one large highlight value, a short title, and an icon, laid out in a fixed width grid. The block is a composition layer, so it paints no surface on its own and expects the base .box class for the border and background.

class: .block-box - defined in blocks/_block-box.scss

Basic usage

Build the tile from three children in this order: the highlight value, the icon, then the title. The block uses a two column grid with a 10px gap, so the value and the icon share the first row and the title spans both columns underneath.

Pair the block with .box. .block-box.scss only sets the grid, the fixed width, the color token, and the hover state; the border, radius, and background come from the Box module. The canonical admin demo uses an anchor so each tile navigates to its list view.

128 Open tickets
HTML 
<a href="#" class="box block-box">
    <span class="block-box-hl">128</span>
    <svg class="block-box-icon" width="24" height="24" viewBox="0 0 24 24" fill="none" aria-hidden="true" focusable="false">
        <path d="M4 7h16M4 12h16M4 17h10" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" />
    </svg>
    <span class="block-box-title">Open tickets</span>
</a>

The tile is a fixed --r-block-box-size of 15.625rem (250px) and takes its spacing from --r-block-box-spacing, which defaults to --r-block-padding. .block-box-hl renders at 32px in the bold weight with --r-block-box-hl-color, and .block-box-title renders at 14px in the inherited block color.

Rows of boxes

.block-boxes is the row wrapper: a wrapping flex container with the block padding token as its gap. Because each tile keeps its own fixed width, the row reflows by wrapping instead of stretching the tiles.

Keep the highlight value scannable and the title short. The value is the only element in the tile with its own weight and size, so a long title competes with it rather than supporting it.

For a uniform dashboard grid with equal columns, use the Block grid wrapper instead. .block-boxes is the right choice when the tiles should keep one size and wrap naturally.

Hover state

Hovering a tile flips it to the accent: the text becomes --r-block-box-hover-color (the on-accent value), and the background and border both become --r-block-box-hover-background (the accent itself). The icon and the highlight value are repainted with the same hover color so all three layers stay legible on the accent fill.

The transition covers color, background, and border, so the change is smooth without any extra class. Hover the tiles below to see it.

The state colors all come from the token layer: --r-block-box-hover-color and --r-block-box-hover-background for the tile, plus --r-block-box-icon-color and --r-block-box-hl-color for the resting icon and value. Changing the accent palette token repaints the hover state in both themes, and overriding --r-block-box-hover-background on a wrapper gives a group of tiles a different hover fill.

Icons

.block-box-icon sets only the placement, the 24px size, and the --r-block-box-icon-color color, so it works with any icon system. The canonical admin demo puts it on an Iconoir font icon (<i class="iconoir-multiple-pages block-box-icon"></i>), which paints with color.

With inline SVG, keep the markup at 24px and draw with currentColor. The class then controls the color, including the hover repaint, and the SVG inherits it. Hide the graphic from assistive technology with aria-hidden="true" and focusable="false", because the title already carries the meaning.

Use a non-interactive element for a tile that only reports a number. The anchor form is for navigation, and it needs a visible focus ring, which the framework already provides on :focus-visible.

Accessibility

A tile is a number, a label, and an icon on one surface, so the work is in the element you pick and the name it produces.

  • When a tile navigates, keep it an <a> and keep the title text inside that link, so the accessible name is Open tickets and not just 128.
  • Keep the focus state visible. The framework paints a :focus-visible ring on links, so do not remove the outline to make the hover fill look cleaner.
  • Hide the icon from assistive technology with aria-hidden="true" and focusable="false", as the demos do, because the title already carries the meaning.
  • Do not put information only in the hover state. The hover fill is a pointer-only decoration, so anything a reader needs has to be in the resting text.
  • Write the highlight value so it reads correctly, and let the title carry the unit or the subject when the number alone is ambiguous.
  • Use a <div> for a tile that only reports a value. An anchor without a destination puts a dead stop in the tab order.

Class reference

The block needs the base .box class for its surface. Every other class belongs to the block.

Class Applies Notes
.block-boxes Row wrapper Wrapping flex row with --r-block-padding as the gap.
.block-box Tile Two column grid with a 10px gap, --r-block-box-spacing padding, and a fixed --r-block-box-size width of 15.625rem. Pair with .box for border and background.
.block-box-hl Highlight 32px bold value in --r-block-box-hl-color, repainted on hover.
.block-box-title Title 14px label that spans both grid columns, so it sits under the value and the icon.
.block-box-icon Icon End aligned 24px icon in --r-block-box-icon-color, repainted on hover.
