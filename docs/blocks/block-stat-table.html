Block stat table

The stat table is a compact analytics table: a wide label column with an optional value bar, followed by right aligned metric columns. It is built from divs on a CSS grid instead of a native table, so the markup stays short while the module owns the column widths and the alignment.

class: .block-stat-table - defined in blocks/_block-stat-table.scss

Basic usage

Four elements are structural. .block-stat-table is the wrapper, .block-stat-table-head holds one .block-stat-table-header per column, .block-stat-table-body holds the .block-stat-table-row elements, and each row holds one .block-stat-table-cell per column.

The wrapper and the body are flex columns with a 5px gap, a quarter of --r-block-padding. The head and every row run the same grid template, so the columns line up as long as both contain the same number of cells with the same spans. The wrapper sets 14px text, the head drops to 12px in --r-block-stat-table-header-color, and every cell pads 6px and aligns its text to the right.

The head is bold and uppercased, and its color is the faint text token, so the labels recede behind the numbers. The module has no row hover, no selected state, and no border between rows: the 5px gap is the only separator, and a clickable row needs its own hover and focus rule.

Column spans and alignment

The same modifier set lives on both the header and the cell: is-left switches the 6px cell from right to left alignment, is-primary makes the element span three grid tracks, and is-secondary spans two. The classes are nested under the header and the cell in the stylesheet, so they do nothing on other elements.

Alignment is not inherited from the head, so a column is declared twice: the header needs is-left and so does every cell in that column. Spans are declared twice for the same reason, and a mismatch shows up as shifted columns because the head and each row are separate grids.

The track template is repeat(auto-fit, minmax(0, 1fr)), so the tracks it creates are equal fractions of the row width. The primary column keeps three shares of that width and a secondary column keeps two, while each metric keeps one.

Text and indicator layers

A cell can carry a value bar behind its text. .block-stat-table-indicator is absolutely positioned against the cell, which is the positioning context, and fills the full height of it with --r-block-stat-table-indicator-color and --r-global-border-radius. Its width is the only value the module does not own: you set it inline as a percentage measured from the data.

.block-stat-table-text lifts the label above that bar. The bar is a positioned element with a zero z-index, so it paints over plain in-flow text; the text class adds relative positioning and a z-index of one, which puts the content back on top. Wrap any cell content that must stay readable above a bar.

Compute the width when you render the row, as a share of the largest value in the column, and clamp it at 100%. A bar over 100% escapes the cell and paints into the neighbour. A zero value can either show no bar at all or a hairline, but it should not be the only place the number appears.

Bars are decoration, so they add nothing to the reading order and need no label. The number stays in the metric cell, and a reader who cannot see the bar still gets the full comparison from the value plus the header.

Responsive columns

The module has no breakpoint of its own. The track template holds at every width, so the columns compress instead of stacking, and minmax(0, 1fr) lets a track fall below the width of its content. The primary column keeps its three shares against one for each metric, so the label column has the most room to give while the numbers get tight.

The block does not scroll either, unlike .table-responsive for native tables. On a narrow screen, drop the least useful metrics or put your own overflow container around the block. A track that shrinks past its content stops the row from widening, so a long path wraps at its slashes where it can and overflows its cell where it cannot; add overflow-wrap: anywhere in your own layer when labels may be that long. A short label column and three metrics fit a sidebar width, which is the layout the analytics page uses.

Accessibility

The block is a grid of div elements, so it has no table semantics. A screen reader reads each row as a run of text and cannot move from a cell to the header above it, which is why visual column alignment does not survive into the accessibility tree.

  • When the numbers are real data that a reader has to navigate, use the table module with <th scope="col"> instead of this block.
  • If the block has to stay, add the roles yourself: role="table" on the wrapper, role="rowgroup" on the head and the body, role="row" on each row, role="columnheader" on the headers, and role="cell" on the cells, and keep the head first in the document.
  • The head is uppercased with text-transform, so write the labels in sentence case and let the module do the casing.
  • Write units into every metric cell. An empty cell reads as nothing, so use a dash or n/a when a value is missing.
  • The bar is an empty element with no text, so the value has to carry the ranking on its own; keep the bar width in sync with the number instead of treating it as a second data source.

Class reference

Two component tokens control the look: --r-block-stat-table-header-color for the head and --r-block-stat-table-indicator-color for the bar. Both default to theme tokens, so light and dark mode follow without an override, and the spacing comes from --r-block-padding, which the module divides by four.

Class Applies Notes
.block-stat-table Wrapper Flex column with a 5px gap and 14px body text. No outer padding, border, or scroll.
.block-stat-table-head Structure Grid row of headers at 12px, bold, uppercased, in the faint header color.
.block-stat-table-header Head cell 6px padding, right aligned. Carries is-left, is-primary, and is-secondary.
.block-stat-table-body Structure Flex column with a 5px gap between rows.
.block-stat-table-row Structure Grid row that repeats the head template. Spans and cell counts must match the head.
.block-stat-table-cell Body cell 6px padding, right aligned, and a positioning context for the bar. Carries the same three modifiers.
.block-stat-table-text Cell layer Relative positioning and a z-index of one, so the content stays above a value bar.
.block-stat-table-indicator Cell layer Absolute bar at the cell edges with full height and a rounded corner. Width comes from an inline percentage.
.is-left Modifier Left aligns a header or a cell. Only applies inside this block.
.is-primary Modifier Spans three grid tracks. Use it on the header and on every cell of that column.
.is-secondary Modifier Spans two grid tracks. Use it on the header and on every cell of that column.
