Block banner

A block banner is an onboarding or empty state panel: a heading, a paragraph of context, and an optional row of steps that leads the user to the first action. The block supplies spacing and stacking only, so the panel itself is a .box and the step markers are badges.

class: Multiple classes - defined in blocks/_block-banner.scss

Basic usage

The wrapper class .block-banner carries no declarations. It is a namespacing hook for the child classes, and the visual surface comes from the Box module. The canonical demo uses .box.box-large with a .box-body inside so the banner gets the large box spacing and 16px body copy.

.block-banner-title adds half the block padding below the heading, and .block-banner-text adds one and a half times that padding below the paragraph. The text also switches to --r-block-banner-text-color , which defaults to the subtle text token, so the body copy recedes behind the heading.

Welcome to your workspace

Create your first module, then build pages from it. You can upload media files and publish when the content is ready.

HTML 
<div class="block-banner">
    <div class="box box-large">
        <div class="box-body">
            <h5 class="block-banner-title">Welcome to your workspace</h5>
            <p class="block-banner-text">Create your first module, then build pages from it. You can upload media files and publish when the content is ready.</p>

            <div class="button-bundle block-banner-buttons">
                <button class="button button-primary">Get Started</button>
                <button class="button button-text button-primary">Learn More</button>
            </div>
        </div>
    </div>
</div>

Because the padding is expressed in --r-block-padding , the banner follows the same rhythm as the other block pages. Override that token on a wrapper to tighten every banner inside it without touching the individual classes.

Steps

.block-banner-steps is a flex column with the block padding as its gap, and it becomes a row from the medium breakpoint up. Each .block-banner-step takes an equal share of that row with flex: 1 , so three steps always divide the width evenly.

Inside a step, the .block-banner-step-title gets 10px above and 5px below, the .block-banner-step-text uses the same subtle color as the banner text, and .block-banner-step-button gets the full block padding as a top margin to separate the action from the copy.

The step markers are the shared Badge component, and the step actions are plain Button classes. The block does not restyle either of them, so a step button keeps its normal size, color, and hover behavior.

Full banner

The full example stacks all the parts: a heading, a paragraph, a row of steps, and two closing actions in a .button-bundle . Use the bundle for the primary and secondary action because it spaces them with the 10px gap from the Button module, and keep the primary action first in the visual order.

When the banner is only an invitation, drop the steps and keep the heading, the text, and the bundle. When it is a checklist, keep the steps and drop the bundle, so there is exactly one obvious next action.

The steps container adds no margin of its own. The spacing above each step action comes from the 20px top margin on .block-banner-step-button , and the bundle follows the steps block directly, so the vertical rhythm stays even whether the banner ends with steps or with actions.

Accessibility

A banner is a heading, a paragraph of context, and a short sequence of steps, so the markup carries that structure. The block only supplies the spacing, and it does not add semantics of its own.

  • Make the banner title a real heading and keep the heading order around it intact. Pick the level from the page it sits on, and keep the step titles below the banner title rather than at the same level.
  • The steps are a sequence, so say so in the DOM: <ol class="block-banner-steps"> with <li class="block-banner-step"> . The reset already removes the markers and the indent, so the block lays out the same.
  • Keep the step number in the badge text, as in Step 1 . A number that exists only as a visual marker is lost to a screen reader and to anyone reading the page in a text browser.
  • Each step action needs a name that stands on its own, so Add module settings works where Add does not. An icon-only action needs a label or an aria-label .
  • The demo links use href="#" as a placeholder. Ship a real destination, because a link with no target is noise in a link list.

Class reference

.block-banner is a wrapper hook only. The surface and typography come from .box and the heading level you choose.

Class Applies Notes
.block-banner Wrapper No declarations. Namespaces the child classes and holds the box.
.block-banner-title Heading Adds 10px of bottom padding, which is half of --r-block-padding .
.block-banner-text Paragraph Adds 30px of bottom padding and paints with --r-block-banner-text-color .
.block-banner-steps Steps wrapper Flex column with a 20px gap, switching to a row from the medium breakpoint up.
.block-banner-step Step Takes an equal share of the row with flex: 1 .
.block-banner-step-title Step heading 10px top padding and 5px bottom padding.
.block-banner-step-text Step paragraph Uses --r-block-banner-text-color , the same subtle color as the banner text.
.block-banner-step-button Step action 20px top margin, which is the full block padding.
