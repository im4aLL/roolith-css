Block inline

A block inline puts a row of form controls on one baseline: filters, a search box, a few toggles, and the buttons that apply them. It stacks the controls below 640px and turns them into a bottom-aligned row above it, using the existing form and button classes.

class: .block-inline - defined in blocks/_block-inline.scss

Basic usage

.block-inline is the wrapper, and it only restyles descendant .form-label elements: 11px, uppercase, 50% opacity, and 2px of bottom padding. That is what makes a filter row read as compact secondary controls instead of a full form.

.block-inline-form is the row. It is a wrapping flex column with a --r-block-inline-gap gap, and from 640px up it becomes a row aligned at flex-end, which lines every control up along its bottom edge. Fields inside the row drop the 20px bottom margin that .form normally gives them, so nothing pushes the row apart.

Keep the .form class on the same element as .block-inline-form. The block owns the layout; .form is the hook that supplies the field margin, and the block resets it.

HTML 
<div class="block-inline">
    <form class="form block-inline-form" action="#">
        <div class="form-field form-field-search">
            <span class="form-field-search-icon"><i class="icon icon-search"></i></span>
            <input type="search" class="form-input" placeholder="Search invoices" aria-label="Search invoices" />
        </div>

        <div class="form-field">
            <label class="form-label" for="block-inline-status">Status</label>
            <select class="form-select" id="block-inline-status">
                <option value="">All statuses</option>
                <option value="draft">Draft</option>
                <option value="sent">Sent</option>
                <option value="paid">Paid</option>
            </select>
        </div>

        <div class="block-inline-button-group">
            <button type="submit" class="button button-primary">Filter</button>
            <button type="reset" class="button button-outline">Reset</button>
        </div>
    </form>
</div>

The gap token defaults to half of --r-block-padding, so a 20px block rhythm gives a 10px gap in the row, including the space between the buttons. Override --r-block-inline-gap on the wrapper to tighten or loosen the whole row at once.

Labels and alignment

Labels are optional per field but worth keeping in a filter bar. Inside .block-inline they shrink to 11px uppercase at 50% opacity with 2px below. The same .form-label class keeps its 14px form style outside the block, so this is a context rule, not a variant.

.block-inline-v-center aligns a control that has no input box, such as a checkbox or a switch, with the fields beside it. From 640px up the field gets a 37px minimum height and centers its content vertically, so the control lines up with the input boxes around it. Below 640px the class does nothing, because the row is already stacked.

HTML 
<div class="block-inline">
    <form class="form block-inline-form" action="#">
        <div class="form-field">
            <label class="form-label" for="block-inline-recipient">Recipient</label>
            <input type="text" class="form-input" id="block-inline-recipient" value="Accounts team" />
        </div>

        <div class="form-field">
            <label class="form-label" for="block-inline-period">Period</label>
            <select class="form-select" id="block-inline-period">
                <option>This month</option>
                <option>Last month</option>
                <option>This quarter</option>
            </select>
        </div>

        <div class="form-field block-inline-v-center">
            <label class="form-checkbox-label">
                <input type="checkbox" class="form-check-input" />
                Include drafts
            </label>
        </div>

        <button type="submit" class="button button-primary">Apply</button>
    </form>
</div>

The search field in the first example has no visible label because the icon and placeholder carry it. Give that input an aria-label, as the markup does, instead of leaving it unnamed.

Right-aligned section

.block-inline-alt-section groups the controls that should sit at the far end of the row. Up to 640px it is a flex column with the same gap, so it stacks with the fields. From 640px up it takes margin-left: auto, becomes a row, and aligns to flex-end, so it starts after the fields and ends flush with the right edge.

.block-inline-button-group is a plain flex row with the same gap. It keeps a submit and reset pair together without merging their borders, so it is not the same as .button-group and each button keeps its own radius.

HTML 
<div class="block-inline">
    <form class="form block-inline-form" action="#">
        <div class="form-field form-field-search">
            <span class="form-field-search-icon"><i class="icon icon-search"></i></span>
            <input type="search" class="form-input" placeholder="Search projects" aria-label="Search projects" />
        </div>

        <div class="form-field">
            <label class="form-label" for="block-inline-owner">Owner</label>
            <select class="form-select" id="block-inline-owner">
                <option>Anyone</option>
                <option>Design</option>
                <option>Engineering</option>
            </select>
        </div>

        <div class="block-inline-alt-section">
            <div class="form-field form-switch block-inline-v-center">
                <label for="block-inline-published" class="form-switch-label">
                    <input type="checkbox" class="form-switch-input" id="block-inline-published" />
                    <span class="form-switch-slider"></span>
                    <span class="form-switch-slider-text">Published</span>
                </label>
            </div>

            <div class="block-inline-button-group">
                <button type="submit" class="button button-primary">Filter</button>
                <button type="reset" class="button button-outline">Reset</button>
            </div>
        </div>
    </form>
</div>

Filter bar

A real filter bar combines the pieces: a search field, one select per filter, an optional toggle, and the action group. The block only lays them out. Submitting the form, filtering the data, and updating the result count are yours, whether that happens on the server or in submit and reset handlers.

Keep each field to one job and give the row a heading or a label when the filter scope is not obvious. If filtering happens without a submit, move the actions into the change handler and keep the button group for an explicit apply step.

HTML 
<div class="block-inline">
    <form class="form block-inline-form" action="#">
        <div class="form-field form-field-search">
            <span class="form-field-search-icon"><i class="icon icon-search"></i></span>
            <input type="search" class="form-input" placeholder="Search orders" aria-label="Search orders" />
        </div>

        <div class="form-field">
            <label class="form-label" for="block-inline-channel">Channel</label>
            <select class="form-select" id="block-inline-channel">
                <option>All channels</option>
                <option>Online</option>
                <option>Retail</option>
                <option>Partner</option>
            </select>
        </div>

        <div class="form-field">
            <label class="form-label" for="block-inline-range">Date range</label>
            <select class="form-select" id="block-inline-range">
                <option>Last 7 days</option>
                <option>Last 30 days</option>
                <option>This quarter</option>
            </select>
        </div>

        <div class="form-field block-inline-v-center">
            <label class="form-checkbox-label">
                <input type="checkbox" class="form-check-input" />
                Only refunds
            </label>
        </div>

        <div class="form-field form-switch block-inline-v-center">
            <label for="block-inline-archived" class="form-switch-label">
                <input type="checkbox" class="form-switch-input" id="block-inline-archived" />
                <span class="form-switch-slider"></span>
                <span class="form-switch-slider-text">Archived</span>
            </label>
        </div>

        <div class="block-inline-button-group">
            <button type="submit" class="button button-primary">Apply</button>
            <button type="reset" class="button button-outline">Clear</button>
        </div>
    </form>
</div>

Accessibility

The block changes spacing and label size, not form semantics. Every control still needs a programmatic name, and the row should stay usable with a keyboard and a screen reader.

  • Point every <label> at its control with for and a matching id. When a field has no visible label, as with the search box, add aria-label instead of leaving it unnamed.
  • The 11px uppercase label is a visual transform. The accessible name is still the text in the markup, so write it in sentence case and let CSS change the presentation.
  • The label is rendered at 50% opacity and 11px. Check it against the surface behind it, and do not make it the only visible cue for a field whose purpose is unclear.
  • Set type="submit" and type="reset" explicitly. A button inside a form defaults to submit, which is easy to trigger by accident.
  • Announce filtered results in a live region when the filter runs without a page load, and keep the result count in the same place so the change is easy to find.
  • Keep the native focus ring on every field and button. Do not replace focus with a color change on hover.

Class reference

The block adds four layout classes around the existing form and button modules. No new field, label, or button class is introduced here.

Class Applies Notes
.block-inline Wrapper Restyles descendant .form-label to 11px uppercase at 50% opacity with 2px of bottom padding.
.block-inline-form Form Wrapping flex column with a --r-block-inline-gap gap. A bottom-aligned row from 640px up, and it zeroes the bottom margin of child .form-field elements.
.block-inline-button-group Group Flex row with the same gap. Keeps related buttons separate, unlike .button-group.
.block-inline-v-center Align From 640px up: 37px minimum height with centered content. For checkboxes and switches that have no field box.
.block-inline-alt-section Align Flex column with the gap below 640px. From 640px up: margin-left: auto, row direction, and end alignment.
