Block form

The form block lays out a settings page as one bordered group of rows. Each row puts a title and a short description beside its fields, and the group ends with an action area for the submit and cancel pair.

class: .block-form-group - defined in blocks/_block-form.scss

Basic usage

.block-form-group is the shell. It draws a 1px border in --r-block-form-group-border-color, a radius of twice the global radius, padding of twice the block padding, and a flex column so the rows stack.

.block-form is one row. It is a grid with a single column, and from the medium breakpoint up it splits into two tracks: two parts for the title and three parts for the fields. The row gap is the same as the group padding, and every row except the last draws a bottom border in --r-block-form-border-color with matching margin and padding.

.block-form-secondary is a grid with a single track and a 20px gap, so each .block-grid row inside it stacks with even spacing and handles its own columns. Use .block-grid for the field row and Form for the controls themselves.

Full settings form

Stack as many rows as the settings need inside one group. The last row drops its bottom border, bottom margin, and bottom padding, so the group padding alone closes the block.

.block-form-action is a plain wrapper with align-self: flex-end, which pushes it to the right edge of the group. Put a .button-bundle inside it so the buttons keep their own shape with a 10px gap, and give the secondary action an outline style.

Wrap the whole group in a <form> and keep the action row inside it, so the primary button submits and the browser runs its own validation before the request. .block-form-group adds no width, so place it in a column or a Box to control the measure.

Alternate group

.block-form-group-alt removes the border and the left and right padding, and keeps everything else. Use it when a card or a page section already draws the frame, and the form should sit flush inside it.

Every color and radius in the block comes from the token layer: --r-block-form-group-border-color, --r-block-form-group-border-radius, --r-block-form-group-padding, --r-block-form-border-color, and --r-block-form-text-color. The first three default to the control border, twice the global radius, and twice --r-block-padding.

Accessibility

The block is layout only, so the form semantics come from the markup you place inside it.

  • Give every control a <label> tied with for and a matching id. The row title is not a label, because it names the group rather than one field.
  • Keep .block-form-title on a real heading element and match its level to the page. Two rows at the same level should use the same tag.
  • When .block-form-text carries a requirement rather than a description, reference it with aria-describedby on the controls it applies to.
  • Use the error and warning classes on .form-field together with a .form-text message, and add aria-invalid="true" when the field has failed validation.
  • Wrap the group in a <form> so Enter submits and native validation runs. A <button type="submit"> inside the form needs no script.
  • Do not disable the submit button as the only guard against a double submit. Set aria-busy="true" on the form while the request is in flight, and keep the focus ring visible on every control and button.

Class reference

The block assembles the group, the rows, and the action area. The fields, labels, selects, and buttons are documented on their own pages.

Class Applies Notes
.block-form-group Group 1px border, twice the global radius, twice the block padding, and a flex column for the rows.
.block-form Row Single-column grid that becomes 2fr title and 3fr fields from the medium breakpoint up. Every row but the last has a bottom border, margin, and padding.
.block-form-primary Row cell Title column. Carries no styles of its own; it exists in the canonical markup to hold the heading and description.
.block-form-secondary Row cell Field column. A single-track grid with a --r-block-padding gap, so each .block-grid inside it stacks.
.block-form-title Heading Adds half the block padding (10px) below the heading.
.block-form-text Description Quiet text color from --r-block-form-text-color.
.block-form-action Action row Aligns itself to the right edge of the group.
.block-form-group-alt Group modifier Drops the border and the left and right padding for a flush form inside an existing frame.
