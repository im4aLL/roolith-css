Dropdown

A dropdown pairs a trigger with a panel of links. The base styles open the panel on hover, and the .active state on the wrapper keeps it open for click and keyboard driven menus.

class: .dropdown - defined in modules/_dropdown.scss

Basic usage

.dropdown is inline-block and relative, which makes it the anchor for the absolutely positioned panel. The panel itself stays hidden until the wrapper is hovered, so the demo below opens when the pointer is over the button.

The demos add a .spacer-* element inside the demo box so an open panel has room and does not cover the code sample underneath. That spacer is documentation scaffolding, not part of the component, so it is left out of the snippets. It is paired with .full-width so it takes its own flex line in the demo container.

HTML 
<div class="dropdown">
    <button class="button has-dropdown-icon" type="button">Actions</button>
    <div class="dropdown-body">
        <a class="dropdown-item" href="#">Rename</a>
        <a class="dropdown-item" href="#">Duplicate</a>

    </div>
</div>

The trigger does not have to be a button. Any element can sit in the wrapper, but a real <button> is the only one that brings the keyboard and focus behavior a menu needs.

Items, separators, and text

.dropdown-item is a block link with 5px of vertical and 15px of horizontal padding. The first and last children also get 5px of outer margin, so the list never touches the panel border, and the background and text color only transition on hover.

.dropdown-item-sep is a 1px rule that spans the panel, and .dropdown-body-text gives a prose block 15px of padding when the panel holds more than links.

Icon button

.has-dropdown-icon draws a downward triangle in the ::after pseudo-element, so no icon font or extra element is needed. The triangle is sized by --r-dropdown-icons-size with 25px of left margin and a 2px vertical nudge that centers it against the label.

The size modifiers are matched on the same element: .button-small:after uses the small triangle token and .button-large:after uses the large one with a wider 35px gap. Because the triangle is CSS, it inherits the button's text color.

Open state

Hover alone is not enough. It does not exist on touch devices, and the panel closes as soon as the pointer leaves the wrapper, which makes a menu hard to use with a mouse. The stylesheet rules out both problems with one selector: .active .dropdown-body is display: block.

Add .active to the .dropdown wrapper to hold the panel open. The selector matches any ancestor, so an .active class higher up also opens it, which is useful for a menu opened from a toolbar state.

JavaScript

roolith css ships no JavaScript. CSS can render the open state but it cannot toggle a class on click, so the panel needs a few lines of script for touch and keyboard use. The snippet below is documentation only and matches the hooks this page uses.

JavaScript 
const dropdown = document.querySelector('.dropdown');
const trigger = dropdown.querySelector('.has-dropdown-icon');

/**
 * Toggle the open state and keep aria-expanded in sync.
 * @returns {void}
 */
function toggleDropdown() {
    const open = dropdown.classList.toggle('active');
    trigger.setAttribute('aria-expanded', open ? 'true' : 'false');
}

trigger.addEventListener('click', toggleDropdown);

document.addEventListener('click', (event) => {
    if (!dropdown.contains(event.target)) {
        dropdown.classList.remove('active');
        trigger.setAttribute('aria-expanded', 'false');
    }
});

document.addEventListener('keydown', (event) => {
    if (event.key === 'Escape' && dropdown.classList.contains('active')) {
        dropdown.classList.remove('active');
        trigger.setAttribute('aria-expanded', 'false');
        trigger.focus();
    }
});

For more than one dropdown on a page, track the open element instead of closing every instance on each document click, and close the open panel when another one opens.

Accessibility

A hover panel is invisible to keyboard users, so the click driven .active path is the one to ship. The rest is menu semantics.

  • The trigger must be a <button type="button"> so it is reachable with Tab and activated with Enter and Space. A div with a click handler is not a button.
  • Set aria-expanded="true|false" on the trigger, point aria-controls at the id of .dropdown-body, and keep both in sync with .active. CSS alone cannot report the open state.
  • Items should be links or buttons, never bare div elements, so they are focusable and respond to Enter. Every item needs visible text; an icon-only item needs an accessible name.
  • Escape closes the panel and returns focus to the trigger. Clicking outside should close it too, so a stray open panel never traps the next click.
  • The hover behavior fires whenever the pointer crosses the wrapper, which can open the panel on the way to something else. If that is a problem, keep the panel closed on hover and rely only on .active.
  • The CSS triangle is decorative and generated content, so there is nothing to label for screen readers.

Class reference

Surfaces, borders, and the item colors come from the --r-dropdown-* tokens. The panel is fixed at --r-dropdown-width, which defaults to 13.75rem.

Class Applies Notes
.dropdown Wrapper Inline-block anchor. Opens the panel on hover and holds .active.
.has-dropdown-icon Trigger CSS triangle in ::after, sized by the icon size tokens.
.dropdown-body Panel Hidden until hover or an .active ancestor, then a bordered 13.75rem surface.
.dropdown-item Item Block link with 5px by 15px padding and a hover background and color.
.dropdown-item-sep Separator 1px rule across the panel. Use a span, since it carries no content.
.dropdown-body-text Prose block 15px padding for a note inside the panel.
.active State on the wrapper Keeps the panel open. The selector matches any active ancestor.
