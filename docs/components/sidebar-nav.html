Sidebar nav

The sidebar nav is a vertical menu for application and documentation navigation. It groups links under short headers, marks the current page with one state class, and folds into an icon rail on narrow screens.

class: .sidebar-nav - defined in modules/_sidebar-nav.scss

Basic usage

.sidebar-nav is only a wrapper and carries no declarations of its own. The group supplies the spacing and the separator, and the list item owns the active state, so the wrapper exists to scope one navigation region and to hang the compact modifier on.

Each group pads itself with --r-sidebar-nav-padding vertically and half of it horizontally, then closes with a 1px line from --r-sidebar-group-sep-color. The last group drops both the line and its bottom padding, so the stack ends flush.

The link is a flex row with a 7px gap, 8px of vertical padding, and a color transition. .is-active on the list item paints the item with --r-sidebar-nav-active-background-color and switches the link to --r-sidebar-nav-active-color; hover paints the label with --r-sidebar-nav-link-hover-color, which is the accent color in the light theme.

Wrap the label in .sidebar-nav-list-label rather than putting text straight into the link. The label element is what the collapsed state hides, and it is also the slot that carries the label weight token.

Groups

Repeat .sidebar-nav-group for each section of the menu. The header is 11px, uppercase, and painted with --r-sidebar-nav-header-color, a faint text tone that keeps it below the links in the hierarchy.

The header, the label, the badge, and the caret all switch on at the 1024px breakpoint and stay hidden below it. A narrow sidebar therefore shows bare rows with no group titles, which suits a rail of icons but means a phone layout needs another way to label the sections.

The badge slot exists for one reason: it takes margin-left: auto and pushes itself to the right edge of the row. It carries no chip styling of its own, so pair it with .badge for a count or a short status and use a color modifier such as .badge-danger when the count is a warning.

Nested lists

A second .sidebar-nav-list inside a list item is a nested group. The module hides it by default, indents it 12px, and cancels the item's right padding so nested rows reach the group edge.

.is-open on that inner list reveals it, but only from 1024px up. Below that breakpoint the reveal rule is still display: none, which is why the collapsed sidebar never leaks sub items.

The caret is a 5px border triangle drawn by .sidebar-nav-list-dropdown and sized by --r-sidebar-nav-item-caret-size. It always points down and does not react to the open state, so the open cue has to come from your own rotation or from aria-expanded on the parent link.

A caret is placed before a badge in the row, and the module hands the auto margin to the caret once it is present, so .sidebar-nav-list-dropdown + .sidebar-nav-list-badge sits directly after it instead of at the far edge. Nested items also drop the 3px vertical margin that top level items keep.

An active parent paints the whole item, which includes any open nested list, because the nested list sits inside that item. Mark the individual page you are on with .is-active on its own nested item as well when you want the leaf row to stand out.

Compact rail

Add sidebar-nav-compact to the wrapper for the collapsed state. It hides the header, the label, the caret, and any nested list, turns the list into an inline-block, and raises the link to 16px, which is the right size for a single icon per row.

The badge stops being a chip in this mode. It becomes a 6px dot in --r-sidebar-nav-badge-dot-color, pinned 4px from the top and 5px outside the right edge of the link, with its text collapsed to nothing by a zero font size and hidden overflow.

The compact class is a separate modifier, not a media query. Toggle it from your own script when the rail collapses, and keep the full sidebar as the markup that expands again. Set --r-sidebar-nav-badge-dot-color if the accent dot needs to read as a specific status.

Accessibility

The nav is a list of links, so the states that matter are the current page and the open or closed nested list. Both need markup, because neither class is announced.

  • Use <nav> with an aria-label for each navigation region, so a page with a sidebar and a breadcrumb can tell them apart.
  • .is-active is visual only. Add aria-current="page" to the link of the current page, and keep exactly one current link per navigation.
  • A nested list needs a control. Put aria-expanded="true|false" and aria-controls on the parent link or button, and update them together with .is-open.
  • Nested lists are display: none until they gain .is-open, and even then only from 1024px up. Their links are unreachable below that width, so keep every destination reachable from the top level or from another entry point.
  • The group header is plain text in a div. If the grouping carries meaning, use a heading element or point aria-labelledby at the header from the list.
  • Compact mode hides labels with display: none, so the text leaves the accessibility tree. Give each compact link its own aria-label.
  • The compact badge keeps its text in the accessibility tree because only the font size is zeroed. Either write the full name in the link label, as the demo does, or mark a decorative dot aria-hidden="true".
  • Keep the global focus ring. The link transitions color only, so the outline from the base layer remains visible on :focus-visible.

Class reference

Structure classes nest three levels deep at most: wrapper, group, list, item, link. The tokens behind them are listed with the component.

Class Applies Notes
.sidebar-nav Wrapper No declarations of its own. Scopes the navigation and receives the compact modifier.
.sidebar-nav-group Group Vertical and half horizontal padding plus a bottom separator. The last group drops the separator and the bottom padding.
.sidebar-nav-header Group title 11px uppercase faint label. Hidden below 1024px.
.sidebar-nav-list List A nested list is hidden, indented 12px, and pulled out on the right. .is-open reveals it from 1024px up.
.sidebar-nav-list-item Item Horizontal padding, radius, and 3px vertical margin. Nested items drop the margin.
.is-active State on the item Paints the item with the active background and the link with the active color.
.is-open State on a nested list Displays the nested list from 1024px up. It has no effect below that breakpoint.
.sidebar-nav-list-link Link 14px flex row, 7px gap, 8px vertical padding, color transition, accent hover.
.sidebar-nav-list-label Label span Weight from --r-sidebar-nav-list-label-font-weight, shown from 1024px up only.
.sidebar-nav-list-badge Badge slot Pushes itself right with an auto margin and shows from 1024px up. Pair it with .badge.
.sidebar-nav-list-dropdown Caret 5px downward border triangle in the current color. Takes the auto margin away from a following badge.
.sidebar-nav-compact Modifier on the wrapper Hides headers, labels, carets, and nested lists, raises links to 16px, and turns badges into accent dots.
