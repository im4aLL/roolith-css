Form extended

The extended module covers controls the base field set does not: switches, card-style radio groups, a styled range input, and the wrappers that add a calendar or clock icon to a date or time field. Each piece is opt-in markup that sits on top of the field system from the Form page.

class: .form-switch and .form-radio-group - defined in modules/_form-extended.scss
These classes style markup only. The switch is a real checkbox, the range is a real range input, and the date and time fields are native inputs, so all keyboard and form behavior still comes from the browser. A JavaScript datepicker is a third-party concern, documented on the Datepicker page.

Switches

.form-switch is the row: a flex container with an 8px gap, centered items, and a 14px label. Inside it, .form-switch-label wraps the real checkbox and the slider so the whole control is clickable and the label text is not selectable.

The checkbox itself is .form-switch-input, absolutely positioned, fully transparent, and pushed behind the surface with z-index: -1. It stays in the accessibility tree and keeps its keyboard behavior; the sibling selector :checked + is what drives the visual state. .form-switch-slider is a pill whose width comes from --r-form-switch-size (36px) and whose height is half of that, with a 14px knob that slides from one edge to the other.

.form-switch-large swaps in --r-form-switch-size-large (44px) and repositions the checked knob for the wider track. Put it on the same wrapper as .form-switch.

HTML 
<div class="form-field form-switch">
    <label class="form-switch-label">
        <input class="form-switch-input" type="checkbox" name="notifications" checked />
        <span class="form-switch-slider"></span>
        <span class="form-switch-slider-text">Email notifications</span>
    </label>
</div>

<div class="form-field form-switch">
    <label class="form-switch-label">
        <input class="form-switch-input" type="checkbox" name="beta" />
        <span class="form-switch-slider"></span>
        <span class="form-switch-slider-text">Join the beta channel</span>
    </label>
</div>

<div class="form-field form-switch form-switch-large">
    <label class="form-switch-label">
        <input class="form-switch-input" type="checkbox" name="compact" checked />
        <span class="form-switch-slider"></span>
        <span class="form-switch-slider-text">Compact tables</span>
    </label>
</div>

The order matters: the checkbox must be the immediate previous sibling of the slider, because both the fill and the knob position are driven by .form-switch-input:checked + .form-switch-slider. Text placed after the slider inside the label acts as the switch label; use .form-switch-slider-text for its 8px offset.

A switch is a checkbox with a different look, so keep name and value on the input and read its checked state exactly as you would for any other checkbox. The input is what gets submitted; the slider is decoration.

Radio groups

.form-radio-group turns a radio list into a row of cards. It is a flex row with a 10px gap, and each .form-radio-item inside it gains a 1px border, a radius of twice --r-form-input-radius, the token padding (20px), a 10px gap between the radio and the copy, and a 300px maximum width.

Selection is drawn with :has(.form-radio:checked): the bordered card takes the accent border and the --r-form-radio-selected-background-color fill, which is a very light primary tint in the light theme and a muted neutral in the dark theme. That means the card highlight follows the checked radio, so a group needs a checked option or a real empty state.

.form-radio-hl is the option title, nudged up 3px with 5px of bottom padding. .form-radio-text is the 12px supporting line below it. .form-radio-group-vertical stacks the same cards in a column, and the group's .form-radio is set to position: static so it sits in the flow next to that copy.

Range input

.form-range removes the native appearance, sets the track to --r-form-range-height (6px) with the token radius, and paints the track as a two-stop gradient. The filled part runs to --r-form-range-value in the thumb color and the rest uses the track color, so the token, not the browser, decides how much of the track looks filled.

The knob is an 18px circle from ::-webkit-slider-thumb, sized from the track height, colored with the thumb token, and darkened on hover. The thumb rule only targets the WebKit pseudo-element, so Firefox draws its own native thumb against the styled track.

--r-form-range-value defaults to 50%. Set it to match the value you render, and update it on input if the control is interactive.

Applies to every signed-in session.
HTML 
<div class="form-field">
    <label class="form-label" for="timeout">Session timeout</label>
    <input class="form-range" type="range" id="timeout" name="timeout" min="0" max="100" step="5" value="30" style="--r-form-range-value: 30%" />
    <small class="form-text">Applies to every signed-in session.</small>
</div>

To keep the fill in step while dragging, recompute the percentage and write it back to the same custom property: range.style.setProperty('--r-form-range-value', `${(range.value - range.min) / (range.max - range.min) * 100}%`). The framework ships no script for this.

Date and time fields

.form-datepicker and .form-timepicker are wrappers around a normal .form-input. They remove the native appearance, fix the input height at 39px, hide the browser's calendar indicator, and draw a calendar or clock icon in the wrapper's ::after pseudo-element at 10px from the bottom and right. The icon has pointer-events: none, so clicks pass through to the input.

small and large adjust the input height to 27px and 44px and move or resize the icon to match. The dark theme swaps the icon for a lighter stroke. The native datetime-local, month, and week inputs use the same datepicker wrapper.

.form-datepicker-js adds 32px of right padding for a field that opens a library panel instead of the native picker. The panel skin lives in modules/_datepicker.scss and is documented on the Datepicker page. The picker behavior itself comes from the browser or from a third-party library, never from this framework.

HTML 
<div class="form-field form-datepicker">
    <label class="form-label" for="start-date">Start date</label>
    <input class="form-input" type="date" id="start-date" name="start-date" />
</div>

<div class="form-field form-timepicker">
    <label class="form-label" for="sync-time">Daily sync</label>
    <input class="form-input" type="time" id="sync-time" name="sync-time" min="09:00" max="17:00" step="900" value="09:30" />
</div>

<div class="form-field form-datepicker">
    <label class="form-label" for="cutover">Cutover</label>
    <input class="form-input" type="datetime-local" id="cutover" name="cutover" />
</div>

<div class="form-field form-datepicker form-datepicker-js">
    <label class="form-label" for="window">Release window</label>
    <input class="form-input" type="text" id="window" name="window" placeholder="Select a date" />
</div>

The text input inside .form-datepicker-js is still a text input, so it needs the library to fill it and it needs a real label. Without the library, use a native type="date" input and let the browser provide the picker.

Accessibility

These controls are thin skins over native inputs, which is the point: keep the native element and the keyboard behavior comes for free. The gaps are in the visual layer, and they are the ones to check.

  • The switch input is hidden with opacity: 0 and sits behind the surface, so the framework draws no focus ring for it. Add a visible focus style on the slider with .form-switch-input:focus-visible + .form-switch-slider, and never replace the input with a styled div.
  • Keep the switch text inside the label so the whole control is clickable and named. If the text sits outside the label, connect it with aria-labelledby.
  • Label a radio group as a group. A <fieldset> and <legend> is the simplest option, or use role="radiogroup" with aria-labelledby pointing at the .form-label.
  • The accent border on a checked card is decoration. The radio's checked state is what assistive technology announces, and arrow keys are what move between options.
  • Give the range a label and show its current value as text. A gradient fill and a thumb position are not announced; an <output> element or a text readout next to the field is.
  • Prefer the native date and time inputs. If you swap in a library panel, keep the label on the visible input, announce the selected value when it changes, and make sure the panel traps Tab and closes on Escape.

Class reference

All classes come from the extended module, except the shared field wrapper, label, text, and size modifiers that the base form module already defines.

Class Applies Notes
.form-switch Switch wrapper Flex row with an 8px gap, centered items, and 14px text.
.form-switch-large Switch modifier Sets --r-form-switch-size to the 44px large token and adjusts the checked knob offset.
.form-switch-label Switch label Clickable flex wrapper. Holds the input, the slider, and the optional text.
.form-switch-input Switch input Native checkbox, transparent and offset, still focusable and still the state owner.
.form-switch-slider Switch track Pill track sized from --r-form-switch-size, filled with the accent when checked.
.form-switch-slider-text Switch text Inline text after the slider with an 8px left margin.
.form-radio-group Radio group Flex row of bordered cards with the --r-form-radio-group-gap gap.
.form-radio-group-vertical Group modifier Stacks the cards in a column. The gap token still applies.
.form-radio-item Option card Inside the group it gains the border, doubled radius, 20px padding, and a 300px maximum width. The accent border and the selected fill follow the checked radio.
.form-radio-hl Option title Card heading with 5px of bottom padding, offset 3px upward.
.form-radio-text Option copy 12px line on an 18px height in the radio text color.
.form-radio Radio Static inside the group so it flows next to the copy. The control stays native.
.form-range Range input Custom track with a gradient fill up to --r-form-range-value and a WebKit thumb.
.form-datepicker Date wrapper 39px input with a calendar icon in ::after. Supports .small and .large.
.form-timepicker Time wrapper Same wrapper with a clock icon instead of the calendar.
.form-datepicker-js Date wrapper Adds 32px of right padding for a library panel. The panel skin is in modules/_datepicker.scss.
