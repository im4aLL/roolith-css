Quick menu

A quick menu is a compact switcher for a few related views, such as a chart range or a list layout. The wrapper draws one muted surface and every link is a pill inside it, so the current choice reads as a raised tile rather than a separate button.

class: .quick-menu - defined in modules/_quick-menu.scss

Basic usage

The wrapper is a <ul> with one <li> per choice. The base class sets inline-flex, a radius from --r-global-border-radius, a fill from --r-quick-menu-background, and a font size from --r-quick-menu-font-size.

Padding and gap both derive from --r-quick-menu-spacing: the wrapper pads itself with half of it and uses the same half as the flex gap, while each link pads itself with the full spacing vertically and one and a half times the spacing horizontally. At the default token values that is 4px of wrapper padding and gap, and 8px by 12px inside each link.

Hover and the active state share one fill, --r-quick-menu-link-hover-background, so the current choice and the hovered choice look the same. That token resolves to --r-surface in the light theme and --r-surface-page in the dark theme, which keeps the pill one step above the muted wrapper in both modes.

.quick-menu-item is unstyled markup rather than framework styling: _quick-menu.scss has no .quick-menu-item selector. Keep the element because it keeps the list semantic and because it is the element that holds the active class, which the next sections rely on.

Sizes

small and x-small do not restate the padding or the font size on the links. Each modifier redeclares --r-quick-menu-font-size and --r-quick-menu-spacing on the wrapper, and the wrapper padding, the flex gap, and the link padding all read those properties, so every measurement follows from two declarations.

x-small also drops the wrapper fill and the wrapper padding. At that size the menu reads as a row of text links, and the active link switches to --r-quick-menu-background because there is no wrapper surface left to contrast against.

The small pair resolves to a 12px font over a 5px spacing, and the x-small pair to a 10px font over a 4px spacing. Override --r-quick-menu-spacing-small or --r-quick-menu-font-size-small where you load the tokens if a whole page needs a tighter or looser small menu; set the pair on a single element only when one menu should differ from the rest.

Active link

The active state is an ancestor match, not a class on the link. The module styles the link for :hover and for .active &, so active belongs on the .quick-menu-item that wraps the link. Adding it to the <a> itself paints nothing.

No script moves the class for you. Set it on the item that matches the current view on load, and move it when the view changes, keeping at most one active item per menu.

Icons

The link is inline-flex, so an icon and a label share one line and stay centered together. The module adds no gap between them, so an icon that sits next to text needs its own spacing, either an inline margin or a spacing class of your own. Icon-only links need nothing extra because the link padding already supplies the hit area.

<ul class="quick-menu small">
    <li class="quick-menu-item active">
        <a class="quick-menu-link" href="#">
            <i class="icon icon-small icon-download" style="margin-right: 6px"></i>
            CSV
        </a>
    </li>
</ul>

The framework ships two masked icons, .icon-search and .icon-download, and .icon paints them with --r-icon-color. .icon-small drops the box to 14px for tighter rows. For any other glyph use an inline SVG at 16px and mark it aria-hidden="true", as the live demo does.

Accessibility

The component renders as a list of links and nothing more, so every state that matters has to live in the markup as well as in the class.

  • .active is visual only. Mirror it with aria-current="page" on a navigation link, or with aria-pressed on a toggle button, and update both together.
  • Use real <a href> elements for navigation. A link without an href is not focusable and is not announced as a link.
  • The wrapper is inline-flex and does not wrap, so keep labels to one or two words. A long menu overflows its container instead of breaking to a second line.
  • Give every icon-only link a name with aria-label and hide the icon from assistive technology, because a masked .icon renders no text.
  • Keep the global focus ring. The module transitions background and color only, so the outline from the base layer stays visible on :focus-visible.

Class reference

Every size class stacks onto .quick-menu and works by redeclaring the two local spacing and font tokens.

Class Applies Notes
.quick-menu Wrapper Inline-flex pill with a muted fill, the global radius, half-spacing padding and gap, and the base font size.
.quick-menu-item Convention Unstyled structural element. The module has no selector for it; the list item only holds the .active class that the link selector reads.
.quick-menu-link Link Inline-flex link with full-spacing vertical padding, 1.5x horizontal padding, the global radius, and a background and color transition.
.small Modifier on the wrapper Redeclares the spacing and font size tokens to the small pair: 5px and 12px.
.x-small Modifier on the wrapper Redeclares the tokens to the x-small pair, 4px and 10px, and also clears the wrapper fill and padding. The active link then uses the muted fill.
.active State on the item Fills any .quick-menu-link inside it with the hover token. On an .x-small menu the fill falls back to the muted background.
