Comment

A comment stacks an author block, body text, and a row of actions. The .comment base class owns the spacing, while .comment-group draws the dividers between entries in a thread.

class: .comment - defined in modules/_comment.scss

Basic usage

The author block reuses the avatar component, so .avatar .avatar-small with .avatar-fig and .avatar-label already handles the image, the name, and the handle.

.comment itself only carries padding of 20px on the top and sides. The top border and the divider between entries come from .comment-group in the next section, so a single entry can sit inside a card or panel without a stray rule.

Actions

.comment-info is the small dimmed metadata row. Repeat it when you need a second line such as a like summary, since each row carries 20px of bottom padding and has no marker of its own.

Actions go in a ul.comment-action. Every .comment-action-item floats left with 15px of right padding and the quiet text color, so a leading span can hold a count before the link. The .comment-action-item-link is an inline-flex row with a 5px gap for the icon and label, and only the color transitions.

The examples use Iconoir class names on the i elements, matching the framework examples. Load the Iconoir stylesheet described on the Introduction page if the glyphs are missing; the text labels stay readable without it.

Comment group

.comment-group draws the top border and gives every nested .comment a bottom border, so a list of entries reads as one divided block.

Put the whole thread in a single group and keep pagination or a "show more" control inside it, so the dividers line up with the entries.

Indented replies

Replies use .comment-indent-1 through .comment-indent-10. Each step adds 5% of the container width, because the class maps the step number to a percentage, so the indentation scales with the column instead of using fixed pixels.

Keep replies inside the same .comment-group as their parent so the dividers and padding stay consistent. Two or three levels are usually enough before the remaining width gets too narrow on small screens.

States

.comment-highlight paints the entry with --r-comment-highlight-color, which is the usual way to mark a pinned or unread comment in a thread.

.comment-blurred applies a 2px blur at 40% opacity. The text stays in the DOM and stays selectable, so treat it as a visual gate only; if the content must not be readable, do not send it to the browser.

Accessibility

Comments are prose plus a small set of links, so the markup carries most of the work. The rules below cover what the classes cannot express.

  • Actions are real <a href> elements with visible text. When an action is icon only, keep an aria-label on the link and mark the icon aria-hidden="true".
  • The avatar image is decorative because the author name sits next to it. Keep alt="" and do not repeat the name in the alternative text.
  • Use <time datetime="2025-03-04T09:12"> when the timestamp matters; a relative label such as "23 min ago" is helpful to read but useless to a parser.
  • .comment-blurred does not remove text from the accessibility tree. Do not rely on it to hide content from anyone, including screen reader users.
  • Indentation is visual only. If nesting changes the meaning of a reply, expose it in the text or with a heading, and keep the reading order parent first.
  • The highlight color comes from a token. Check the contrast of the body text on that background in both light and dark mode.

Class reference

Borders come from --r-comment-border and the highlight from --r-comment-highlight-color. Both follow the active theme.

Class Applies Notes
.comment Wrapper 20px padding on the top and sides. No divider on its own.
.comment-group Thread wrapper Top border plus a bottom border on each nested comment.
.comment-body Body text 14/22 with 15px of vertical padding.
.comment-info Metadata row Small dimmed text with 20px of bottom padding. Repeat as needed.
.comment-action Action list Clears the floated items and adds 20px of bottom padding.
.comment-action-item Action list item Floats left with 15px of right padding and the quiet text color.
.comment-action-item-link Action link Inline-flex with a 5px gap for icon and label; transitions color only.
.comment-indent-1 Reply depth Margin left of step / 20, so 5% per step up to .comment-indent-10.
.comment-highlight State Paints the background with --r-comment-highlight-color.
.comment-blurred State 2px blur at 40% opacity. Visual only, the text stays in the DOM.
.comment-small Density 12/18 body text with 10px of vertical padding.
