Breadcrumb

Breadcrumb renders the trail of parent pages above the current one as an ordered list. Items float and the separators are generated by CSS, so the markup carries no slash or chevron text of its own.

class: .breadcrumb - defined in modules/_breadcrumb.scss

Basic usage

Use an ordered list of .breadcrumb-item entries. Each entry renders a separator after itself, and the last entry drops it, so the trail never ends with a dangling slash.

The list is set to 80% size in the subtle text color. Links inside it use the global link color and are not underlined, because the trail is not prose.

  1. Dashboard
  2. Reports
  3. Quarterly
HTML 
<ol class="breadcrumb">
    <li class="breadcrumb-item"><a href="#">Dashboard</a></li>
    <li class="breadcrumb-item"><a href="#">Reports</a></li>
    <li class="breadcrumb-item"><a href="#">Quarterly</a></li>
</ol>

Active item

The current page is a plain item without a link, marked with .active and placed last. The framework has no styling rule for the marker; the visual difference comes from the item being text rather than a link.

Keep the active item last. The separator is removed by the :last-child selector, not by the class, so an active item in the middle of the trail still shows a separator after it.

  1. Dashboard
  2. Reports
  3. Data
HTML 
<ol class="breadcrumb">
    <li class="breadcrumb-item"><a href="#">Dashboard</a></li>
    <li class="breadcrumb-item"><a href="#">Reports</a></li>
    <li class="breadcrumb-item active">Data</li>
</ol>

Long trails

Separators and spacing come from custom properties: --r-breadcrumb-sep-symbol defaults to a slash and --r-breadcrumb-spacing sets 0.625rem on each side.

There is no truncation or collapsing rule. Items float, so a trail wider than its container wraps between items and the separator stays attached to the item it follows. Keep labels short, or drop the middle of a deep trail in your own markup.

  1. Dashboard
  2. Projects
  3. Billing
  4. Invoices
  5. 2025
  6. June
HTML 
<ol class="breadcrumb">
    <li class="breadcrumb-item"><a href="#">Dashboard</a></li>
    <li class="breadcrumb-item"><a href="#">Projects</a></li>
    <li class="breadcrumb-item"><a href="#">Billing</a></li>
    <li class="breadcrumb-item"><a href="#">Invoices</a></li>
    <li class="breadcrumb-item"><a href="#">2025</a></li>
    <li class="breadcrumb-item active">June</li>
</ol>

With page headers

Place the trail at the top of a .block-header and let the header handle the vertical rhythm. The header adds half of the block padding below the trail, which separates it from the title without extra wrappers.

  1. Dashboard
  2. Reports
  3. Data
Report data

Last synced 12 minutes ago.

HTML 
<div class="block-header">
    <ol class="breadcrumb">
        <li class="breadcrumb-item"><a href="#">Dashboard</a></li>
        <li class="breadcrumb-item"><a href="#">Reports</a></li>
        <li class="breadcrumb-item active">Data</li>
    </ol>
    <h5>Report data</h5>
    <p>Last synced 12 minutes ago.</p>
</div>

Accessibility

The breadcrumb module styles a list but does not create a navigation landmark. Wrap the list in a <nav> with a label, and mark the current page for assistive technology in addition to the visual class.

  • Wrap the trail in <nav aria-label="Breadcrumb"> so it is announced as navigation.
  • Put aria-current="page" on the last item, or on its link when it stays clickable.
  • Keep the ordered list: the position carries the hierarchy that the separators show visually.
  • Give each link a name that makes sense on its own, since screen readers can list links out of context.
  • Do not add separator text to the markup. The generated ::after content is not relied on for meaning.
  1. Dashboard
  2. Reports
  3. Data
HTML 
<nav aria-label="Breadcrumb">
    <ol class="breadcrumb">
        <li class="breadcrumb-item"><a href="#">Dashboard</a></li>
        <li class="breadcrumb-item"><a href="#">Reports</a></li>
        <li class="breadcrumb-item active" aria-current="page">Data</li>
    </ol>
</nav>

Class reference

The module only styles the list and its items. There is no separate separator element to add.

Class Applies Notes
.breadcrumb Base Ordered list at 80% size in the subtle text color, cleared with a clearfix.
.breadcrumb-item Item Floats left and generates the separator after itself, except when it is the last child.
.active Marker Convention for the current page. No styling rule of its own.
