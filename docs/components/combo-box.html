Combo box

A combo box is a trigger button with a dropdown list attached to it. The base class provides the positioning context, the menu is a plain list, and a single open class reveals it. Submenus, group headers, and separators are all optional parts of the same list.

class: .combo-box - defined in modules/_combo-box.scss

Basic usage

Wrap the trigger and the menu in .combo-box, which is an inline-block with relative positioning and left-aligned text. The menu is absolutely positioned under the trigger at top: 100%, so it never pushes the surrounding layout around.

The menu is hidden by default and only becomes visible when the root has .open. That class is the whole CSS contract; roolith css ships no JavaScript, so the trigger wiring in the JavaScript section below is what adds and removes it.

HTML 
<div class="combo-box">
    <button class="button button-primary button-has-icon" type="button" data-doc-combo-box>
        Actions
        <svg width="16" height="16" viewBox="0 0 24 24" fill="none" aria-hidden="true" focusable="false">
            <path d="M6 9l6 6 6-6" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" />
        </svg>
    </button>
    <ul class="combo-box-menu">
        <li class="combo-box-item"><a class="combo-box-link" href="#">Rename</a></li>
        <li class="combo-box-item"><a class="combo-box-link" href="#">Duplicate</a></li>
        <li class="combo-box-item"><a class="combo-box-link" href="#">Archive</a></li>
    </ul>
</div>

The menu is 13.75rem wide by default, takes its surface from --r-combo-box-background, and fades in over --r-combo-box-show-animation-duration at 50ms using the shared fadeIn keyframes. Change the width with --r-combo-box-width on the root when labels need more room.

Click the trigger in the demo above: doc-surfaces.js toggles .open on the closest .combo-box and closes any other open combo box, while doc.js handles the outside click and Escape routing that closes this one.

Right aligned menu

Add combo-box-right to the root when the trigger sits at the right edge of its container. The menu then anchors its right edge to the trigger instead of its left edge, and any nested submenu opens to the left so it stays inside the viewport.

Submenu

Put a ul.combo-box-submenu inside a li.combo-box-item to nest a second level. The item gains an automatic right-pointing triangle from a generated element, and the submenu opens when the item is hovered, offset to the right of the parent menu.

Submenus nest to any depth because each one is positioned against its own item. With combo-box-right, the submenu flips to the left side of the parent menu instead.

The submenu is only revealed by :hover on the item. There is no focus or click trigger in the CSS, so a keyboard user cannot reach the second level without extra script. See the accessibility section before shipping a submenu to a keyboard audience.

Group headers and separators

A group header is a li.combo-box-item.combo-box-item-header. It uses the same padding as a link but renders 12px uppercase text in --r-combo-box-item-header-color, so it labels a block of items without being clickable.

A separator is an empty li.combo-box-item.combo-box-item-sep. It draws a 1px rule in --r-combo-box-item-sep with vertical margins equal to the item padding.

Both classes are modifiers on .combo-box-item, so keep the base item class in the markup. A header is a label, not an option, and a separator is decoration; neither should be focusable or carry a link.

Primary and secondary rows

Every link is a flex row. combo-box-primary groups the label and an optional inline icon with a 5px gap, and combo-box-secondary is the trailing meta slot at 12px in --r-combo-box-secondary-color. The row keeps the two apart with justify-content: space-between and a 10px minimum gap.

The usual secondary value is a keyboard shortcut, but a count or a status word works too. Keep it short: the menu width is fixed, and a long secondary string competes with the primary label for room in the same row.

Links set their own 14px label size, 1.3 line height, item padding, and the --r-combo-box-item-color token, then transition background and color. Hover paints --r-combo-box-item-hover-background-color and the theme decides --r-combo-box-item-hover-color: muted text in light mode, strong text in dark mode.

JavaScript

The component needs script to open and close. roolith css ships no JavaScript; this is a complete minimal behavior for the demos on this site, kept here so you can copy it into your own page.

JS 
document.querySelectorAll('[data-doc-combo-box]').forEach((trigger) => {
    trigger.addEventListener('click', () => {
        const combo = trigger.closest('.combo-box');
        const willOpen = !combo.classList.contains('open');

        document.querySelectorAll('.combo-box.open').forEach((open) => open.classList.remove('open'));
        combo.classList.toggle('open', willOpen);
        trigger.setAttribute('aria-expanded', String(willOpen));
    });
});

document.addEventListener('click', (event) => {
    if (event.target.closest('.combo-box')) {
        return;
    }

    document.querySelectorAll('.combo-box.open').forEach((combo) => {
        combo.classList.remove('open');
        combo.querySelector('[data-doc-combo-box]').setAttribute('aria-expanded', 'false');
    });
});

document.addEventListener('keydown', (event) => {
    if (event.key !== 'Escape') {
        return;
    }

    document.querySelectorAll('.combo-box.open').forEach((combo) => {
        combo.classList.remove('open');
        combo.querySelector('[data-doc-combo-box]').setAttribute('aria-expanded', 'false');
    });
});

The trigger uses a data hook rather than an id, so one script handles every combo box on the page. The handler reads the closest .combo-box, records whether it was open before closing the others, and then restores that state, which is what lets the same button both open and close its own menu.

The demos on this page rely on doc-surfaces.js to toggle .open and close other menus, and on doc.js for outside-click and Escape routing. Neither touches aria-expanded, so the snippet above adds that bookkeeping and keeps the attribute truthful.

Accessibility

Keep the trigger a real <button type="button"> so focus, Enter, and Space work without extra code. The menu itself is a list of links, which is the simplest structure to announce.

  • Add aria-haspopup="true" and aria-expanded="false" to the trigger, and flip aria-expanded whenever .open changes, as the JavaScript snippet does. The demo triggers omit the attribute because doc-surfaces.js does not update it.
  • The CSS only opens submenus on :hover, so keyboard focus never reveals them. Add a focus or click path that toggles the submenu, and if the parent becomes a real button, give it aria-expanded too.
  • Only use role="menu" and role="menuitem" if you implement the full menu keyboard model: arrow keys, Home and End, Escape, and focus movement into the menu. For a list of links, plain list semantics are more honest and need no extra keys.
  • Close on Escape and return focus to the trigger, and close on an outside click without stealing focus.
  • Keep the focus ring visible on both the trigger and the links. Do not remove it, and do not rely on the hover fill as the only state cue.
  • Mark the separator as decoration with role="separator" or aria-hidden="true", and keep group headers as plain text that is not focusable.

Class reference

The root class holds the position, the menu class holds the panel, and the item classes hold the rows and their optional parts.

Class Applies Notes
.combo-box Base Inline-block positioning context with left-aligned text.
.open State On the root. Reveals .combo-box-menu.
.combo-box-right Alignment Anchors the menu to the right edge and flips submenus to the left.
.combo-box-menu Panel Absolutely positioned list at 100% from the top, 13.75rem wide, token surface and shadow, 50ms fade in.
.combo-box-item Row Block row with a relative position. Hovering it reveals a nested submenu.
.combo-box-link Row Flex row with space-between, 14px text, item padding, and hover fill.
.combo-box-primary Content Flex group with a 5px gap for the label and an optional icon.
.combo-box-secondary Content 12px trailing meta or shortcut in the secondary color.
.combo-box-submenu Submenu Nested list inside an item, shown on hover and offset beside the parent menu.
.combo-box-item-sep Divider On an empty item. Draws a 1px rule with vertical margins.
.combo-box-item-header Label On an item. 12px uppercase group label in the header color, with item padding.
