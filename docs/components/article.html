Article

The article component is a prose shell for long-form content. It lifts body copy to a 16px base with a 26px line height, sets consistent rhythm between paragraphs, figures, lists and quotes, and adds an optional single-column layout for reading pages.

class: .article - defined in modules/_article.scss

Basic usage

Wrap the content in .article and use normal HTML inside it. Paragraphs, blockquotes, definition lists, .list, and .list-numbered all move to 16/26 and keep 20px of space underneath, while the last child drops its bottom padding so the article does not end on empty space.

The heading pairs .article-header with .article-subheader. The subheader renders at 60% of the heading size with normal weight and half opacity. Add .blocked to push it onto its own line.

.article-header carries 25px of bottom padding declared with !important so a surrounding layout rule cannot collapse the gap under the title.

Primary layout

Add .article-primary to center the prose in a measured column. The article becomes a three column grid with 10px side columns, a 20px gap, and the content in the middle column. From 640px up the side columns grow to 100px.

Only direct children participate. Figures and blockquotes span the whole grid, and an <aside> moves into the right column once the page reaches 1024px, so a note can sit beside the paragraph it belongs to.

Figures

Use the figure element with .fig and a .fig-caption. Inside an article the figure gets a 20px bottom margin, and inside .article-primary it spans the full grid with 20px 40px 40px margins from 640px up.

.fig-caption is a 14/18 caption in the muted image caption color. .img-full-width stretches the image to the figure width; without it the image keeps its natural size.

The summary card now reserves its final height before data arrives, which removes the layout shift that appeared on slow connections.

HTML 
<article class="article">
    <p>The summary card now reserves its final height before data arrives, which removes the layout shift that appeared on slow connections.</p>
    <figure class="fig">
        <img src="../images/placeholder-800x300.png" alt="Placeholder for the dashboard screenshot"
            class="img-full-width" />
        <figcaption class="fig-caption">The summary card reserves space before the first request resolves.</figcaption>
    </figure>
</article>

Lists

Add .list to a ul for disc markers, or .list-numbered to an ol for decimal markers. Both use the article prose size and keep 20px of space underneath; nested lists sit 30px in from their parent.

Accessibility

The component is a wrapper around semantic markup, so the reading experience depends on the elements you put inside it.

  • Keep one h1 per page and choose the article heading level to match the document outline. The demos use h3 because this page already has an h1 and section h2 elements.
  • Leave .article-subheader inside the heading element. Its smaller size and opacity are presentational, and a screen reader should announce it as part of the title.
  • Use figure and figcaption so the caption is associated with the image. Describe the image in alt or leave alt="" when the caption already carries the full description.
  • Use ul for .list and ol for .list-numbered so sequence and item counts are announced.
  • .article-primary moves asides with CSS grid only, so the DOM order still drives reading order. Keep a note next to the paragraph it annotates.
  • The component raises body copy from the 14px base to 16/26. The primary layout only sizes the side columns, it does not cap the overall width, so set a maximum width on the article for long-form pages.

Class reference

The article classes style content you already have. Figures and captions come from the image module.

Class Applies Notes
.article Container Prose at 16/26 with 20px of space underneath, dimmed asides, no trailing gap.
.article-header Heading 25px bottom padding, declared with !important.
.article-subheader Span inside the header 60% size, normal weight, 50% opacity.
.blocked Subheader modifier Displays the subheader on its own line.
.article-primary Article modifier Centered grid with 10px side columns, 100px from 640px up.
.fig Figure inside an article 20px bottom margin. Spans the grid and gains 20px 40px 40px margins at 640px up.
.img-full-width Image Sets width: 100% so the image fills the figure.
.fig-caption Figcaption 14/18 caption in the muted image caption color.
.list Unordered list inside an article Disc markers, nested lists supported, 20px bottom padding.
.list-numbered Ordered list inside an article Decimal markers with the same spacing as .list.
aside Element, no class Small and dimmed in an article, italic and moved to the third column at 1024px in .article-primary.
