Button

Buttons signal actions. The .button base class owns the shared shape, padding, and hover and press behavior, while color, size, and variant classes fine-tune the look. Everything below stacks onto that one base class, so a button is always one base class plus as many modifiers as the job needs.

class: .button - defined in modules/_button.scss
The base button reads its resting colors from the --r-button-* tokens, while every colored variant derives its fill, border, and text from the palette (--r-color-primary, --r-color-primary-on, --r-color-primary-text). Override a palette token and all button variants follow.

Basic usage

Start with the base class and a label. It works on <button> elements and on links that navigate.

The base sets an inline-flex box, centers the label, uses a 14px label over normal line height, and adds 9px by 20px of padding with a 60px minimum width. Hover raises the fill one step and adds a hairline shadow, and the native active state moves the button down by 1px.

Open documentation
HTML 
<button class="button" type="button">Save draft</button>
<a class="button" href="#">Open documentation</a>

Use the --r-button-radius, --r-button-default-background, --r-button-default-border, and --r-button-default-color tokens to retune the uncolored button, including the matching --r-button-default-hover-* tokens for the hover state.

Colors

Append a palette name to the base class. Each variant pulls its fill from --r-color-<name>, its label from --r-color-<name>-on, and its border from a 5% darker version of the fill, so the label contrast is decided by the palette rather than by the page.

HTML 
<button class="button" type="button">Default</button>
<button class="button button-primary" type="button">Primary</button>
<button class="button button-secondary" type="button">Secondary</button>
<button class="button button-tertiary" type="button">Tertiary</button>
<button class="button button-info" type="button">Info</button>
<button class="button button-success" type="button">Success</button>
<button class="button button-warning" type="button">Warning</button>
<button class="button button-danger" type="button">Danger</button>
<button class="button button-link" type="button">Link</button>
<button class="button button-dark" type="button">Dark</button>
<button class="button button-black" type="button">Black</button>
<button class="button button-light" type="button">Light</button>

The palette loop skips white, so no .button-white class is generated by _button.scss. Use the uncolored base button for a neutral control and .button-light when you need a fixed light fill. .button-dark, .button-black, and .button-light keep the same fill in both themes because they are fixed palette values, not theme surfaces.

Outline buttons

Add button-outline for a transparent fill that keeps the border and label color. Colored outline buttons read --r-color-<name>-text, the text-safe version of the palette, and fill with a slightly darker version of the solid color on hover.

HTML 
<button class="button button-outline" type="button">Default</button>
<button class="button button-primary button-outline" type="button">Primary</button>
<button class="button button-secondary button-outline" type="button">Secondary</button>
<button class="button button-success button-outline" type="button">Success</button>
<button class="button button-warning button-outline" type="button">Warning</button>
<button class="button button-danger button-outline" type="button">Danger</button>
<button class="button button-dark button-outline" type="button">Dark</button>
<button class="button button-black button-outline" type="button">Black</button>

A light outline on a light surface has almost no contrast. Put .button-light.button-outline on a dark or inverted surface, or switch to the solid or text variant when the background is unknown.

Text buttons

Add button-text to drop the border and fill entirely and raise the label to the bold weight. Hover paints the shared --r-surface-hover surface without a shadow, which makes text buttons the right choice for low-emphasis actions inside cards, toolbars, and table rows.

HTML 
<button class="button button-text" type="button">Cancel</button>
<button class="button button-primary button-text" type="button">Edit</button>
<button class="button button-secondary button-text" type="button">Duplicate</button>
<button class="button button-danger button-text" type="button">Delete</button>
<button class="button button-link button-text" type="button">View logs</button>

Sizes

Four sizes cover dense toolbars through prominent calls to action. Small and medium share a 12px label and a 50px minimum width, but medium keeps a taller padding box; the default size sits at 14px with 9px by 20px of padding, and large moves to 16px with 11px by 30px.

HTML 
<button class="button button-small button-primary" type="button">Small</button>
<button class="button button-medium button-primary" type="button">Medium</button>
<button class="button button-primary" type="button">Default</button>
<button class="button button-large button-primary" type="button">Large</button>

Size classes are plain modifiers, not nested under .button, so they also change the minimum width of a standalone element. Keep the base class in place; the size class only adjusts type and padding.

Rounded buttons

Add button-rounded for a pill radius of 25px and a 120px minimum width. It combines with color, outline, text, and size classes, and it is useful for marketing surfaces, empty states, and single primary actions.

HTML 
<button class="button button-rounded button-primary" type="button">Get started</button>
<button class="button button-rounded button-outline" type="button">Learn more</button>
<button class="button button-rounded button-primary button-small" type="button">Small pill</button>

Block and bundle

button-block stretches a button to the full width of its container. It is the usual choice in a narrow form column, a drawer footer, or a mobile action area.

button-bundle is a flex wrapper with a 10px gap for grouping related actions without merging them. A bundle keeps the shape of each button, unlike a button group, and it is the right wrapper for a cancel and save pair.

HTML 
<button class="button button-primary button-block" type="button">Publish release</button>

<div class="button-bundle">
    <button class="button button-outline" type="button">Cancel</button>
    <button class="button button-primary" type="button">Save changes</button>
</div>

Button groups

button-group joins adjacent buttons into one shape. The group clears its own floats, each button floats left, the next button pulls back by 1px so the shared border stays a single line, and only the outer corners keep the radius.

Day Week Month
Left Center Right
HTML 
<div class="button-group">
    <a class="button button-primary" href="#">Day</a>
    <a class="button button-primary active" href="#">Week</a>
    <a class="button button-primary" href="#">Month</a>
</div>

<div class="button-group">
    <a class="button" href="#">Left</a>
    <a class="button active" href="#">Center</a>
    <a class="button" href="#">Right</a>
</div>

The group needs the wrapper: the float and the negative margin only apply to buttons inside .button-group. Grouped buttons also lose their minimum width, so group labels size themselves from their content.

Icon buttons

button-icon adds a 5px flex gap between the icon and the label, and the module also gives any .icon inside a button a 5px right margin. Use the framework icon classes (.icon .icon-download and .icon .icon-search) or your own inline SVG.

button-has-icon widens the gap to 20px for buttons where the icon is a separate visual element, such as an arrow that points out of the button. A colored button repaints .icon with currentColor, so the icon follows the label color automatically.

Create report
HTML 
<button class="button button-primary button-icon" type="button">
    <i class="icon icon-download"></i>
    Download report
</button>

<button class="button button-icon" type="button" aria-label="Search">
    <i class="icon icon-search"></i>
</button>

<a class="button button-has-icon" href="#">
    Create report
    <svg width="16" height="16" viewBox="0 0 24 24" fill="none" aria-hidden="true" focusable="false">
        <path d="M5 12h14M13 6l6 6-6 6" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" />
    </svg>
</a>

An icon-only button needs an accessible name. aria-label on the button is enough, and the icon itself should be presentational: an empty alt for an image, or aria-hidden="true" for an inline SVG. Do not put the only label inside a masked .icon, because the mask renders no text.

States

active adds an inset shadow to mark a pressed or current choice. It works on top of any variant and is the same class used by the middle item of a button group.

disabled drops the button to 60% opacity, sets a not-allowed cursor, and turns off pointer events. loading hides the label with a negative text indent, disables pointer events, sets a wait cursor, and draws a spinner in the center with the shared loader mixin. The spinner is 20px by default and 12px, 16px, and 24px for the small, medium, and large buttons.

HTML 
<button class="button button-primary active" type="button">Active</button>
<button class="button button-primary disabled" type="button" disabled>Disabled</button>
<button class="button button-primary loading" type="button" aria-busy="true">Saving</button>
<button class="button button-outline loading" type="button" aria-busy="true">Saving</button>

.active is a visual class only. If the pressed state has meaning, mirror it with aria-pressed on a toggle button or aria-current on a navigation link, and keep the class in sync with that attribute.

Accessibility

Choose the element by behavior, not by look. A button performs an action in the page, a link navigates to a URL, and the styling classes work on both.

  • Use <button type="button"> for actions, and set type="submit" or type="reset" explicitly inside a form. A button without a type defaults to submit.
  • Use <a href> for navigation. An anchor without href is not focusable and is not announced as a link, so style a real button instead.
  • The .disabled class is visual only. On a button, also add the native disabled attribute. On a link, add aria-disabled="true" and remove the href or block activation in script, because pointer-events: none does not stop keyboard activation.
  • Give every icon-only button a name with aria-label or visually hidden text, and hide the icon from assistive technology.
  • For .loading, set aria-busy="true" and disable the control so a second submit cannot fire. The label stays in the accessibility tree because the text is only indented out of view, so write it as the in-progress action, and announce completion elsewhere if the user needs confirmation.
  • Keep the global focus ring visible. Do not remove outlines or replace them with a hover-only cue, and keep the pressed state in a real attribute when it carries meaning.

Class reference

Every modifier class stacks onto the .button base, except the standalone layout helpers listed at the end.

Class Applies Notes
.button Base Inline-flex box, 14px label, 9px by 20px padding, 60px minimum width, token radius, hover fill, and a 1px press offset.
.button-primary Color Any generated palette name: secondary, tertiary, info, success, warning, danger, link, dark, black, light. The source loop skips white.
.button-outline Variant Transparent fill with a colored border and label. Colored variants fill on hover; the uncolored outline keeps its transparent fill.
.button-text Variant No border or fill, bold label, hover uses --r-surface-hover with no shadow.
.button-small Size 12px label, 5px by 10px padding, 50px minimum width.
.button-medium Size 12px label, 6px by 12px padding, 50px minimum width.
.button-large Size 16px label, 11px by 30px padding, 80px minimum width.
.button-rounded Shape 25px radius with a 120px minimum width.
.button-block Layout Full width of the container.
.button-bundle Layout Flex wrapper with a 10px gap for related actions.
.button-group Layout Float-based wrapper that merges adjacent buttons and trims the inner radii.
.button-icon Icon 5px flex gap between icon and label. Use .icon children.
.button-has-icon Icon 20px flex gap for a separated leading or trailing icon.
.icon Icon Masked 16px icon. Inside a colored button it paints with currentColor and gets a 5px right margin.
.active State Inset shadow for a pressed or current choice.
.disabled State 60% opacity, not-allowed cursor, no pointer events. Pair with the native disabled attribute.
.loading State Hides the label, shows a spinner, blocks pointer events, and sets a wait cursor.
