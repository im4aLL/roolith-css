Popover

A popover is a small panel anchored to the control that opened it. Use it for a few lines of explanation, a compact form, or a secondary action that should not take over the screen the way a modal does.

class: .popover - defined in modules/_popover.scss

Basic usage

Wrap the trigger and the panel in .popover-container, which is only position: relative. The panel .popover is absolutely positioned at the bottom left of that container and translated down by its own height plus --r-popover-offset, so it opens below the trigger with its left edge on the trigger's left edge.

The panel is display: none until it carries .active. It caps at --r-popover-width (17.1875rem), pads 15px, and draws a 1px border with the radius token. The background comes from --r-popover-background, which resolves to the muted surface in light mode and the raised surface in dark mode.

HTML 
<div class="popover-container">
    <button type="button" class="button button-outline" data-doc-popover="#popover-quota" aria-controls="popover-quota" aria-expanded="false">
        Plan quota
    </button>
    <div class="popover" id="popover-quota" style="--r-popover-width: 300px; width: 300px;">
        <div class="popover-header">Monthly quota</div>
        <div class="popover-body">
            You have used 8.4 GB of 10 GB. Archive old builds to free space before the next billing cycle.
        </div>
    </div>
</div>

Click the trigger to see it. The data-doc-popover attribute is a docs convention, not a framework hook: it holds a CSS selector for the panel. See the JavaScript section for the script behind it.

Headers and body

The panel takes any number of .popover-header and .popover-body pairs. A header is bold with 16px above it and 8px below, except when it is the first child, which drops the top margin so the panel does not start with an empty band.

Body copy is 14px over a 1.5 line height. A .button inside the body gets 8px of top margin, so actions do not touch the text above them.

Active state

The component has one state: .active on the panel, which switches it from display: none to display: block. There is no animation, so no layout work is needed when it appears.

Start the markup with .active when the panel should be visible on load, for example for a dismissible tip. The class is the only thing CSS sees; the script owns the transitions and must also close the panel on an outside click and on Escape.

JavaScript

roolith css ships no JavaScript. The snippet below is documentation only and matches the behavior this page uses: a trigger toggles the panel, an outside click closes it, and Escape closes it while returning focus to the trigger. It also keeps aria-expanded in sync, which a class toggle alone does not do.

JavaScript 
let lastPopoverTrigger = null;

/**
 * Close every open popover and optionally return focus to its trigger.
 * @param {boolean} restoreFocus - Whether to move focus back to the trigger.
 * @returns {boolean} Whether at least one popover was open.
 */
function closePopovers(restoreFocus) {
    const open = document.querySelectorAll('.popover.active');

    if (!open.length) {
        return false;
    }

    open.forEach((popover) => {
        popover.classList.remove('active');

        const trigger = document.querySelector('[data-doc-popover="#' + popover.id + '"]');
        if (trigger) {
            trigger.setAttribute('aria-expanded', 'false');
        }
    });

    if (restoreFocus && lastPopoverTrigger && document.body.contains(lastPopoverTrigger)) {
        lastPopoverTrigger.focus();
    }

    lastPopoverTrigger = null;

    return true;
}

document.addEventListener('click', (event) => {
    const trigger = event.target.closest('[data-doc-popover]');

    if (trigger) {
        const popover = document.querySelector(trigger.getAttribute('data-doc-popover'));

        if (!popover) {
            return;
        }

        const willOpen = !popover.classList.contains('active');

        closePopovers(false);
        popover.classList.toggle('active', willOpen);
        trigger.setAttribute('aria-expanded', String(willOpen));
        lastPopoverTrigger = willOpen ? trigger : null;

        return;
    }

    if (!event.target.closest('.popover')) {
        closePopovers(false);
    }
});

document.addEventListener('keydown', (event) => {
    if (event.key === 'Escape') {
        closePopovers(true);
    }
});

If you need several panels open at once, drop the closePopovers(false) call before the toggle so opening a second panel leaves the first one in place.

Accessibility

A popover is a disclosure, not a dialog. It does not trap focus and it does not take over the page, so the trigger has to announce the relationship and the state.

  • Use a <button> for the trigger and give it aria-controls pointing at the panel id.
  • Mirror the open state in aria-expanded="true|false" every time the class changes. A screen reader cannot see .active.
  • Do not add role="dialog" or aria-haspopup="dialog" unless you also trap focus, move focus into the panel on open, and return it on close. For a short note or an inline action, plain disclosure semantics are correct.
  • Close on Escape and return focus to the trigger. Close on an outside click without moving focus.
  • Keep every control inside the panel in the normal tab order. The panel stays in the document, so tabbing past the trigger reaches it while it is open.
  • Never put information that exists only in an open popover. The panel is hidden from assistive technology while display: none applies, so the trigger label must still make sense on its own.

Class reference

Two classes shape the panel and its parts; the container only supplies the positioning context. All colors, the width, and the offset come from the --r-popover-* token group.

Class Applies Notes
.popover-container Wrapper Relative positioning context for the trigger and the panel.
.popover Panel Absolute panel below the trigger, 15px padding, 1px border, radius and width tokens, z-index: 1000, hidden by default.
.active State On the panel. Switches it from display: none to block.
.popover-header Part Bold label with 16px above and 8px below; the top margin drops on first child.
.popover-body Part 14px text over a 1.5 line height; a nested .button gets 8px of top margin.
