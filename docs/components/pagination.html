Pagination

Pagination moves a reader through a long result set. The component gives you a list of links with an active state, a numbered mode that collapses on small screens, and a meta row for the range summary and a per page selector.

class: .pagination - defined in modules/_pagination.scss

Basic usage

.pagination is a flex column with a gap from --r-pagination-gap and centered items, so the controls and the meta row stack on narrow screens. From 640px it becomes a row with space-between, which keeps one group on each edge. With a single child the row puts it on the left edge, so a lone link group is centered on phones and left aligned on desktop.

Inside it, .pagination-list is a wrapping flex row with a gap from --r-pagination-list-gap, and .pagination-item holds a .pagination-link. The link height and padding come from --r-pagination-item-height and --r-pagination-item-spacing, and it adds a 1px border, the radius token, and a background transition.

Numbered pages

Add .is-number to every numbered item. The class hides the item below 640px and shows it again from 640px up, except when the item also has .pagination-item-active, which always stays visible. That way a phone shows the controls and the current page only.

The active item carries the accent background and the accent on-color. The gap item is a plain .pagination-item with text instead of a link, so it has no border or background and reads as punctuation.

The legacy example in this repository also puts .is-disabled on the last arrow. The module defines no rule for that class, so a disabled control needs its own styling plus aria-disabled="true", or no link at all.

Meta row

.pagination-meta holds the summary and the page size control. It is a centered flex column with the pagination gap from --r-pagination-gap and switches to a row from 640px, matching the parent direction. Use it as the other child of .pagination beside the list: space-between puts the two groups on opposite edges.

.pagination-meta-label carries the range summary at the item font size and centers below 640px. .pagination-meta-selection is where the form classes compose: the nested .form-field becomes a flex row with the gap from --r-pagination-gap and no bottom margin, and its .form-label loses padding and is set to nowrap. The .form-select keeps its own control chrome, so no extra rules are needed.

Small pagination

.pagination-small on the nav compacts the whole component: the outer gap drops to 8px, the list gap to 4px, the item font to 12px, the link height to 26px, and the link padding to 4px by 8px. The meta label follows the item font token, so the summary shrinks with the controls.

Accessibility

Pagination is a set of links, so it needs a labelling landmark and a current page marker that assistive technology can read.

  • Put the component on a <nav> element with a unique aria-label, such as Search results pages or Audit log pages. Two navs on one page need different labels.
  • Add aria-current="page" to the active link. The fill color alone is not announced, and it disappears for users who cannot see it.
  • Label icon or arrow controls with aria-label such as Previous page, and hide the glyph with aria-hidden="true".
  • Read the summary in .pagination-meta-label as one sentence. Screen readers announce it in order, so keep the numbers inside the text and not in separate fragments.
  • The page size select keeps its .form-label with a matching for attribute. Do not replace it with a placeholder.
  • The active link points at the current page and still needs a visible focus ring, so do not remove the outline on the link.

Class reference

Colors, radius, font size, gaps, item height, and padding come from the --r-pagination-* token group. The 1px border and the 1.3 line height stay fixed in the module.

Class Applies Notes
.pagination Base Flex column, centered, gap from --r-pagination-gap; a space-between row from 640px up.
.pagination-small Variant Compacts the outer and list gaps, item font, link height, link padding, and meta label.
.pagination-list Group Wrapping flex row with a gap from --r-pagination-list-gap.
.pagination-item Row Holds one link or plain text such as an ellipsis.
.is-number Variant On the item. Hidden below 640px unless the item is also active.
.pagination-item-active State On the item. Fills the link with the accent color and keeps a numbered item visible on small screens.
.pagination-link Link 32px-by-default flex link with padding from --r-pagination-item-spacing, a 1px border, the radius token, and a hover surface.
.pagination-meta Group Centered column with --r-pagination-gap; row from 640px up.
.pagination-meta-label Text Item font size, centered, left aligned from 640px up.
.pagination-meta-selection Group Makes the nested .form-field a flex row with --r-pagination-gap and no bottom margin, and strips the label padding.
