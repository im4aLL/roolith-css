Box

Box is a bordered surface for grouping related content, with optional header, body, and footer slots. It is deliberately plain: the container adds the border, radius, and background, while every slot owns its own padding and type scale.

class: .box - defined in modules/_box.scss

Basic usage

The body slot carries the padding, so use .box-body on the content element instead of relying on the container.

Deploys are paused for this environment until the next release window.

HTML 
<div class="box">
    <p class="box-body">Deploys are paused for this environment until the next release window.</p>
</div>

Header, body, and footer

Header and footer are optional slots around the body. The header is bold 14px with no bottom padding, the body runs at 14px over 22px lines, and the footer drops to 80% size with no top padding, so the three slots stay tight without extra markup.

The base class adds no borders between the slots. If you want a divider, style the header or footer element in your own layer.

Sizes

Three sizes change the padding and the type scale together. .box-small uses 0.9375rem of padding with 12px text, the default uses 1.25rem with 14px text, and .box-large uses 2.5rem with 16px text.

Small box

Dense metadata panels and secondary notes.

Default box

The default works for most inline content groupings.

Large box

Roomier panels such as empty states and introductions.

HTML 
<div class="box box-small">
    <div class="box-header">Small box</div>
    <p class="box-body">Dense metadata panels and secondary notes.</p>
</div>

<div class="box">
    <div class="box-header">Default box</div>
    <p class="box-body">The default works for most inline content groupings.</p>
</div>

<div class="box box-large">
    <div class="box-header">Large box</div>
    <p class="box-body">Roomier panels such as empty states and introductions.</p>
</div>

Colors

A color class sets the border and the text of every slot to the same palette value, which keeps the variant readable without a filled background. Every palette name except white is generated, including dark and black.

Accessibility

A box is a visual grouping, not a landmark or a widget. The border adds nothing for assistive technology.

  • Use a real heading element inside .box-header when the box labels a section, so it lands in the document outline.
  • Do not make the box the only cue that content is separate; keep the heading and copy meaningful without the border.
  • When the whole box becomes a link, as in the stat block pattern, keep the anchor semantics and a visible focus style.

Class reference

Slot classes go inside the box. Size and color classes go on the box element itself.

Class Applies Notes
.box Base Border, doubled radius, and surface background. No padding.
.box-header Slot Bold 14px label with no bottom padding.
.box-body Slot 14px over 22px lines and the main padding bearer.
.box-footer Slot 80% size, muted, with no top padding.
.box-small Size Tighter padding with 12px slot text.
.box-large Size Wider padding with 16px slot text.
.box-primary Color Any palette name except white: secondary, tertiary, info, success, warning, danger, link, dark, black, light.
