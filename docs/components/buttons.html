Buttons

Buttons signal actions. The .button base class handles the shared shape and focus behavior, while color, size, and variant classes fine-tune the look.

class: .button - defined in modules/_button.scss
Every variant below is powered by the token layer - override a variable like --r-color-primary and the whole set follows.

Basic usage

Start with the base class. It works on <button> elements and on links that act like buttons.

Link button
HTML 
<button class="button" type="button">Default</button>
<a class="button" href="#">Link button</a>

Colors

Append any palette name to the base class. Each variant pulls its fill, border, and text color from the token layer.

HTML 
<button class="button" type="button">Default</button>
<button class="button button-primary" type="button">Primary</button>
<button class="button button-secondary" type="button">Secondary</button>
<button class="button button-tertiary" type="button">Tertiary</button>
<button class="button button-info" type="button">Info</button>
<button class="button button-success" type="button">Success</button>
<button class="button button-warning" type="button">Warning</button>
<button class="button button-danger" type="button">Danger</button>

Outline buttons

Add button-outline for a transparent fill that keeps the colored border and label.

HTML 
<button class="button button-outline" type="button">Default</button>
<button class="button button-primary button-outline" type="button">Primary</button>
<button class="button button-success button-outline" type="button">Success</button>
<button class="button button-danger button-outline" type="button">Danger</button>

Text buttons

Add button-text to drop the border entirely - useful for low-emphasis actions inside cards and toolbars.

HTML 
<button class="button button-text" type="button">Default</button>
<button class="button button-primary button-text" type="button">Primary</button>
<button class="button button-danger button-text" type="button">Danger</button>

Sizes

Four sizes cover dense toolbars through prominent calls to action. The default size sits between medium and large.

HTML 
<button class="button button-small button-primary" type="button">Small</button>
<button class="button button-medium button-primary" type="button">Medium</button>
<button class="button button-primary" type="button">Default</button>
<button class="button button-large button-primary" type="button">Large</button>

Rounded buttons

Add button-rounded for a pill shape with a wider minimum width - handy for marketing surfaces and empty states.

HTML 
<button class="button button-rounded button-primary" type="button">Get started</button>
<button class="button button-rounded button-outline" type="button">Learn more</button>

States

Interaction states are classes too: active for a pressed look, disabled to block input, and loading to swap the label for a spinner while work is in flight.

HTML 
<button class="button button-primary active" type="button">Active</button>
<button class="button button-primary disabled" type="button">Disabled</button>
<button class="button button-primary loading" type="button">Loading</button>

Class reference

Every modifier class stacks onto the .button base.

Class Applies Notes
.button Base Shared shape, padding, and focus style.
.button-primary Color Any palette name: secondary, tertiary, info, success, warning, danger.
.button-outline Variant Transparent fill that keeps the colored border.
.button-text Variant No border or fill until hover.
.button-small Size Also: button-medium, button-large.
.button-rounded Shape Pill shape with a wider minimum width.
.active State Pressed look. Also: .disabled, .loading.
