Badge

Badges are compact labels for counts, statuses, and short metadata. They render as inline-flex, so they sit inside running text, links, and table cells without breaking the line.

class: .badge - defined in modules/_badge.scss

Basic usage

A badge is a <span> with the base class and a short label. Without a color class it uses the neutral badge tokens.

Build status Pending

HTML 
<p>Build status <span class="badge">Pending</span></p>

Colors

Append any palette name to the base class. Colors other than dark, black, and white produce a tinted chip whose border and label use the palette text value; those three fill the chip with the palette color and switch the label to its on-color.

Sizing and casing

The badge owns its typography: an 11px font size, a line height of 1, and an uppercase transform. It does not inherit the size or the casing of the surrounding text, so a label written in sentence case always renders in capitals.

Padding is 3px by 4px with a 1px border, which keeps the chip tight next to 14px body copy. Text box trimming removes the extra cap height above and below the glyphs, so the label centers optically instead of by font metrics. All of those values are fixed in _badge.scss.

draft active failed
HTML 
<span class="badge">draft</span>
<span class="badge badge-success">active</span>
<span class="badge badge-danger">failed</span>

In context

Because the badge is inline-flex, it drops into links and table cells without extra layout wrappers. Keep the label short and let the surrounding element carry the meaning.

Accessibility

A badge is text, so a screen reader announces its label where it sits in the document. The color is decoration on top of that label.

  • Write the state in the label. A red badge with no text carries no meaning for assistive technology.
  • Do not rely on the color alone for status. Pair it with a word such as Failed or Active.
  • Keep labels to a word or a number so the chip stays readable at 11px.
  • When the badge is only a dot or a count that repeats nearby text, hide it with aria-hidden="true".

Class reference

The color class stacks onto .badge . On the base chip, four values are tokens: --r-badge-surface for the fill, --r-badge-background for the border, --r-badge-color for the label, and --r-badge-border-radius for the chip radius, which defaults to half of --r-global-border-radius. The remaining geometry and type values are fixed in the module: 3px by 4px padding, an 11px font size, and a line height of 1, trimmed to the cap height.

Class Applies Notes
.badge Base Tight inline chip with 11px uppercase text, 3px by 4px padding, a 5px radius, and a 1px border.
.badge-primary Color Any palette name: secondary, tertiary, info, success, warning, danger, link, dark, black, white, light.
