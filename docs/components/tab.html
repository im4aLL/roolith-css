Tab

Tabs swap one panel of content for another without leaving the page. The stylesheet provides the list, the underlined title, and the panel visibility, while a single .active class on the title and on the matching panel decides what is shown.

class: .tab-list - defined in modules/_tab.scss

Basic usage

.tab-list is a cleared list with a 1px bottom border taken from --r-tab-border-color. Each .tab-title floats left, sets a 14px bold label with 10px by 20px of padding, and draws a 2px transparent bottom border. A negative 1px bottom margin pulls that border onto the list line, so the underline of the active title replaces the separator instead of stacking above it.

.tab-content is display: none and pads 15px above and below once it is shown. Only the panel with .active is displayed, so the hidden panels and their links stay out of the tab order.

Roolith css is a small set of component and layout modules compiled into one stylesheet. Import it once, then use the classes directly in your markup.

Install the package with your package manager, or link the compiled file from the build output. No build step is required if you only need the finished CSS.

Override the custom properties on :root to retune colors, radius, and spacing. Component tokens read from them, so a single override flows through the whole library.

.tab itself carries no declarations. It groups one list with its panels, and the docs script uses it as the scope, so several tab groups can live on one page without interfering.

Every title needs its own data-doc-tab value pointing at a unique panel id. The attribute is a docs hook rather than part of the stylesheet, which is why the framework can stay JavaScript free.

Centered list

tab-list-center centers the row by setting text-align: center on the list and switching the titles from a float to an inline-block. The titles still size themselves from their labels, so the list stays as wide as its content unless the parent stretches it.

Fluid list

tab-list-fluid replaces the float with a grid of auto-fit tracks at a 100px minimum and centers each title inside its track. The columns share the available width evenly and the count falls out of the container width, so the same markup shows four columns in a wide panel and two in a narrow one.

The modifier also removes the clearfix pseudo-elements, which are not needed once the list is a grid.

Hover paints the title label with --r-tab-active-color and fills it with --r-tab-border-color at the same time. That fill is a plain surface tone, so it reads as a hovered row rather than a second active state.

JavaScript

roolith css ships no JavaScript. The snippet below is documentation only and matches the behavior this page uses: a click on a title clears .active from its siblings, then sets it on the clicked title and on the panel named by data-doc-tab.

JavaScript 
document.querySelectorAll('.tab-title[data-doc-tab]').forEach((title) => {
    title.addEventListener('click', () => {
        const tab = title.closest('.tab');
        const panel = document.querySelector(title.dataset.docTab);

        tab.querySelectorAll('.tab-title').forEach((item) => {
            item.classList.toggle('active', item === title);
        });

        tab.querySelectorAll('.tab-content').forEach((content) => {
            content.classList.toggle('active', content === panel);
        });
    });
});

Scope every query to the closest .tab so a second tab group on the page is untouched. Keep the hook on the title and let CSS own the visual state; if the panel must also update ARIA attributes, do it in the same handler so the class and the attribute never disagree.

Accessibility

The default markup is a list of clickable list items. That is enough for a visual demo, but a tab widget needs roles, a selected state, and keyboard support before it ships.

  • Put role="tablist" on the .tab-list, role="tab" on each .tab-title, and role="tabpanel" on each .tab-content.
  • Give every title an id and every panel aria-labelledby pointing at its title, then point aria-controls from the title at the panel id.
  • .active is visual only. Mirror it with aria-selected="true" on the current title and false on the rest, and update both in the same handler.
  • Use a roving tabindex: tabindex="0" on the selected title and tabindex="-1" on the others, so the whole list is one stop in the page tab order.
  • Left and Right arrows move to the previous and next title, Home and End jump to the first and last. Move focus with focus() on the newly selected title after the swap.
  • Hidden panels are display: none through the framework, so their controls are already out of the tab order and out of the accessibility tree. Only the active panel is reachable.
  • The tabs in this demo are activated by click and not by keyboard, because a list item is not focusable. The roles and the roving tabindex above are what make the same markup usable with a keyboard.
  • data-doc-tab is a docs hook, not framework API. Its value is a CSS id selector, so every panel id has to be unique on the page.
  • Keep the focus ring. The title transitions color, border, and background only, so the outline from the base layer stays visible on :focus-visible.

Class reference

Titles are styled as a group, so every modifier belongs on the list rather than on the individual title.

Class Applies Notes
.tab Wrapper No declarations of its own. Groups a list with its panels and is the scope the script searches within.
.tab-list List Cleared list with a 1px bottom border from --r-tab-border-color.
.tab-title Title Floated 14px bold label with 10px by 20px of padding, a 2px transparent bottom border, and a 1px negative bottom margin.
.tab-list-center Modifier on the list Centers the row and switches the titles to inline-block with no float.
.tab-list-fluid Modifier on the list Grid of auto-fit 100px minimum tracks, centered titles, and no clearfix pseudo-elements.
.active State on a title Paints the 2px bottom border with --r-tab-active-color.
.tab-content Panel Hidden with 15px of vertical padding applied when shown. Needs its own .active to display.
data-doc-tab Attribute on a title Docs hook holding the panel selector. Not part of the stylesheet.
