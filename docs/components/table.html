Table

Tables carry the rows that other components describe. The .table base class sets a compact 14px grid with token borders and a first-cell padding reset, and the variant classes add striping, a closed border grid, or a filled header. Row state classes mark the selected and the changed rows without touching the markup.

class: .table - defined in modules/_table.scss
Every surface, border, and spacing value in this module reads a --r-table-* token, including the hover, striped, and highlight colors. Retune --r-table-spacing and the whole grid follows, in both themes.

Basic usage

The base class goes on a real <table>. It sets 14px text over an 18px line height, left aligns the headers at --r-table-header-font-weight, and pads every cell by --r-table-spacing, which is 0.625rem by default.

The first cell in each row drops its left padding, so the table lines up with the heading above it instead of sitting 10px to the right. The striped, bordered, and primary variants put that padding back because they own the outer edge themselves.

A table is as wide as its content by default. Add .full-width from the typography module to stretch it to the container, and reach for the responsive wrapper below when the column count can pass the available width.

Bordered rows

.table-bordered draws the top and left border on the table itself and puts the bottom and right border on each cell, which closes a full grid. The header row drops its own bottom border because the cells already provide one, so no line doubles up.

The variant also restores the first-cell left padding and keeps the background transition on body rows. It is the right choice when a row has to be readable across a wide gap, such as a comparison table.

Primary and sortable headers

.table-primary fills the header with --r-table-primary-header-color and transitions the background of every body row to --r-table-row-hover-color on hover. It is the default choice for a data table that a reader scans row by row.

A sortable column needs a control inside the <th>. .table-thead-label is a full width flex button that spreads the label and the sort glyph to opposite edges, resets the background, border, and padding, inherits the cell type, and sets a pointer cursor.

Responsive wrapper

.table-responsive caps the width at the container, scrolls the overflow on the x axis, and pins two edge scrims plus two shadow gradients over the table. The scrims use --r-table-scroll-scrim-color and the shadows use --r-table-scroll-shadow-color.

Two of those gradients scroll with the content and two stay fixed, which is what makes a shadow appear only on a side that still has hidden columns. Once the table is fully visible both shadows disappear, so the effect needs no JavaScript.

The wrapper raises the inner .table to a --r-table-min-width of 30rem so columns do not collapse before the scroll starts, and it applies the shared 4px scrollbar from --r-scrollbar-track and --r-scrollbar-thumb.

In a narrow window, scroll the demo above sideways to see the scrim and the shadow drop away as the last column comes into view.

The conditional tabindex="0" is the one part of this wrapper that the stylesheet cannot supply. The framework ships no JavaScript, so gating the attribute on overflow takes a few lines of script, and this site uses the gate in docs/doc.js, which adds tabindex="0" while a wrapper overflows and removes it once the table fits. Without that gate, decide once: keep tabindex="0" and accept a focus stop when the table fits, or omit it and accept that a narrow viewport cannot reach the scroll.

Row states

.is-highlight tints a row with --r-table-row-highlight-color and draws a 3px inset bar in --r-accent on the first cell. Use it for the row a deep link just landed on, or for the row that a bulk action changed.

.is-checked tints a row with --r-table-row-hover-color. It is a separate class from the checkbox state, so keep the two in sync in your script and do not let the tint carry the meaning on its own.

Invoice Client Amount
INV-1042 Northwind $2,400
INV-1043 Contoso $860
INV-1044 Fabrikam $1,150
HTML 
<tr class="is-highlight">
    <td>INV-1042</td>
    <td>Northwind</td>
    <td>$2,400</td>
</tr>
<tr class="is-checked">
    <td>INV-1043</td>
    <td>Contoso</td>
    <td>$860</td>
</tr>

Both classes go on the <tr>. The highlight bar only appears on the first cell, and it draws inside the cell box, so the bordered variant keeps its grid intact.

Selection column

A checkbox column is an ordinary cell with .form-check-input inside it. The table gives that input a 7px by 12px margin so the control centers against the 18px line instead of sitting on the baseline.

Repeat the input in the header for a select all control, and use .is-indeterminate on it when only some rows are selected. The modifier fills the box with --r-surface-muted, draws the accent border, and renders a dash.

Composition

Cells are plain block content, so badges and buttons drop in without wrappers. Keep row actions small: a .button-text or a .button-small keeps the row height predictable, while a full size button stretches every row to 40px or more.

Accessibility

A table is the right element only when the content has rows and columns that relate to each other. For a two column list of labels and values, use a description list instead.

  • Keep the real table structure: <table>, <thead>, <tbody>, and <th> for the header cells. A grid of <div> elements is not announced as a table.
  • Set scope="col" on column headers and scope="row" on row headers, so a screen reader can pair each cell with its label.
  • Label the table with a <caption> as the first child of <table>. When a nearby heading already names the table, give that heading an id and point aria-labelledby at it instead of repeating the text.
  • Give a scrollable .table-responsive wrapper role="region" and an aria-label whether or not the table overflows, and tabindex="0" while it overflows, so the scroll area is a named region and a keyboard user can scroll with the arrow keys when needed.
  • Every documentation reference table points aria-labelledby at the id of its nearest heading, and the docs wrappers become focusable only while they actually overflow.
  • Give every checkbox in a selection column its own name with aria-label or a visually hidden label, and name the header checkbox by what it does, such as Select all invoices.
  • Move aria-sort="ascending" or aria-sort="descending" onto the <th> of the sorted column, and leave it off the others. The sort glyph is decoration, so hide it with aria-hidden="true".
  • Do not encode state in the tint alone. .is-checked follows the input, and .is-highlight needs a word in the row or a note nearby.

Class reference

The variants stack onto .table. The row classes go on a <tr>, and .table-thead-label goes on a button inside a header cell.

Class Applies Notes
.table Base 14px text over 18px, token borders, --r-table-spacing cell padding, 30px minimum cell width, and no left padding on the first cell.
.table-primary Variant Filled header from --r-table-primary-header-color, restored first-cell padding, and a hover background transition on body rows.
.table-striped Variant Even rows take --r-table-row-striped-color and --r-table-row-striped-hover-color on hover. Shares the primary header and padding rules.
.table-bordered Variant Outer top and left border with bottom and right borders on each cell. The header row drops its own rule.
.table-responsive Wrapper Scrolls on the x axis with edge scrims and shadows, styles a 4px scrollbar, and raises the inner table to --r-table-min-width.
.table-thead-label Header control Full width flex button that spreads the label and the glyph, with the background, border, and padding reset and the cell type inherited.
.is-highlight Row state --r-table-row-highlight-color plus a 3px inset --r-accent bar on the first cell.
.is-checked Row state --r-table-row-hover-color tint. Separate from the input state, so keep both in sync.
.form-check-input Cell control Form checkbox. Inside a table cell it gets a 7px by 12px margin, and .is-indeterminate renders the mixed state.
.full-width Layout helper Typography utility that sets width: 100% on the table. Not part of this module.
