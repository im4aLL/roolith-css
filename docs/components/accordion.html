Accordion

An accordion stacks related questions or panels and reveals one panel on demand. The markup is a list of items, and the open state is a single .active class on the item that owns the panel.

class: .accordion - defined in modules/_accordion.scss

Basic usage

The wrapper .accordion draws the top border and each .accordion-item draws the bottom one, so a stack of items reads as a single block.

Add .active to an item to open it on first paint. The body is display: none until that class is present, so the collapsed panel is not just visually hidden.

How do I install roolith css?

Link the compiled stylesheet in the document head and use the component classes directly.

HTML 
<div class="accordion">
    <div class="accordion-item active">
        <div class="accordion-item-title">How do I install roolith css?</div>
        <div class="accordion-item-body">
            <p>Link the compiled stylesheet in the document head and use the component classes directly.</p>
        </div>
    </div>
</div>

Multiple items

Repeat .accordion-item inside one .accordion for each panel. There is no group class, so every item toggles on its own and several panels can stay open at once.

The title carries a small CSS-drawn chevron in its ::after pseudo-element. It points down while the item is closed and flips when the item gains .active, so no icon font is needed.

Which browsers are supported?

Current versions of Chrome, Firefox, Safari, and Edge. The stylesheet relies on custom properties and color-mix.

Can I override the border color?

Yes. Set --r-accordion-border-color where you load the tokens and both the wrapper and the items follow.

Does it need JavaScript?

The stylesheet only renders the open state. Toggling needs a few lines of script, shown in the next section.

HTML 
<div class="accordion">
    <div class="accordion-item">
        <div class="accordion-item-title">Which browsers are supported?</div>
        <div class="accordion-item-body">
            <p>Current versions of Chrome, Firefox, Safari, and Edge. The stylesheet relies on custom properties and color-mix.</p>
        </div>
    </div>
    <div class="accordion-item active">
        <div class="accordion-item-title">Can I override the border color?</div>
        <div class="accordion-item-body">
            <p>Yes. Set <code>--r-accordion-border-color</code> where you load the tokens and both the wrapper and the items follow.</p>
        </div>
    </div>
    <div class="accordion-item">
        <div class="accordion-item-title">Does it need JavaScript?</div>
        <div class="accordion-item-body">
            <p>The stylesheet only renders the open state. Toggling needs a few lines of script, shown in the next section.</p>
        </div>
    </div>
</div>

JavaScript

roolith css ships no JavaScript. The snippet below is documentation only and is the same behavior this page uses: a click on .accordion-item-title toggles .active on the closest .accordion-item.

JavaScript 
document.querySelectorAll('.accordion-item-title').forEach((title) => {
    title.addEventListener('click', () => {
        title.closest('.accordion-item').classList.toggle('active');
    });
});

Keep the handler on the title element and let CSS own the visual state. If you need only one panel open at a time, remove .active from the other items in the same .accordion before toggling.

Accessibility

The default markup uses plain div elements for titles, which is fine for a visual demo but not for a real page. Upgrade the control and expose the open state before shipping.

  • Use a <button type="button"> as the title control, or wrap the title text in one, so it is reachable with Tab and activated with Enter and Space.
  • Add aria-expanded="true|false" to that button and keep it in sync with the .active class. CSS cannot express expanded state to assistive technology on its own.
  • Point aria-controls at the id of the .accordion-item-body so the relationship is explicit.
  • Collapsed bodies are already display: none through the framework, so their links and text stay out of the tab order and the accessibility tree.
  • Focus rings come from the base layer, which outlines a, button, and [tabindex] on :focus-visible. Do not remove them.
  • The chevron is decorative and drawn in CSS, so there is nothing extra to label for screen readers.

Class reference

The stack is two nested wrappers plus a state class. Borders come from --r-accordion-border-color.

Class Applies Notes
.accordion Wrapper Draws the top border and groups the items.
.accordion-item Item Bottom border with 10px of vertical padding. Carries the open state.
.active State on the item Shows the body and flips the title chevron.
.accordion-item-title Title 16/22 bold label with a pointer cursor and the CSS chevron.
.accordion-item-body Panel Hidden until the parent item is active; adds 10px of top padding.
