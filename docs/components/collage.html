Collage

Collage is a dense CSS grid for a set of images where a few tiles are deliberately larger than the rest. Column count is automatic, row height is fixed by a token, and item classes decide which cells span extra rows or columns.

class: .collage - defined in modules/_collage.scss

Basic usage

Wrap the images in .collage and each direct child in .collage-item. The grid uses repeat(auto-fit, minmax(12.5rem, 1fr)) columns, so the browser fits as many 200px tracks as the container allows and shares the remaining space between them.

Rows are created with grid-auto-rows at a fixed --r-collage-item-default-height of 12.5rem, and grid-auto-flow: dense pulls later cells into holes left by spanning tiles. .collage-item itself only clips overflow, so the media inside has to fill the cell.

.fig-fit comes from the image module and is what makes the tile work: it sets width: 100%, height: 100%, and object-fit: cover, so any image crops to the cell instead of stretching it. A single collage does not set its own width, so place it in a normal block container or add .full-width when it sits inside a flex parent such as a demo panel.

Item sizes

Three item classes change how many grid cells a tile occupies. They are independent, so a tile can be big, wide, or tall, but not a combination of them.

  • .collage-item-big spans two rows and two columns, for the lead image of the set.
  • .collage-item-wide spans two columns and one row, for a panoramic tile.
  • .collage-item-tall spans two rows and one column, for a portrait tile.

Gaps

The default gap is --r-collage-item-default-gap at 0.625rem. Three modifiers replace it on the same element: .collage-small-gap collapses to 1px for a tight contact sheet, .collage-large-gap opens to 1.25rem, and .collage-no-gap removes it entirely for a seamless mosaic.

Figure captions

For a caption, replace the bare image with a figure.collage-fig that holds the image and a figcaption.collage-fig-caption. The figure fills the cell, and the caption is an absolutely positioned overlay across the whole tile.

By default the caption is transparent with 70% black at full opacity and only appears on figure hover. Add .visible to keep it on: the overlay switches to a bottom gradient so the caption sits on the image edge instead of covering it, and the text aligns to the bottom.

The caption overlay takes its backdrop from --r-collage-caption-background, which is an RGB triple rather than a color, and its text from --r-collage-caption-color. Caption text is 12px over 18px lines with 20px of padding, so keep it to a short line or two.

Hover-only captions are unreachable on touch and from the keyboard. When the caption text carries information, use .visible, or repeat the text next to the collage in normal content.

Responsive behavior

There are no breakpoint classes. The column count falls out of auto-fit and the track width, so the same markup shows four columns in a wide panel, two on a tablet, and one on a phone without a media query.

The row height stays fixed, which means tiles keep their size while the column count drops; only the number of visible columns changes. To make the whole grid denser or larger, override the tokens on the collage element, for example style="--r-collage-item-default-width: 8rem; --r-collage-item-default-height: 8rem;".

Keep an eye on spanning tiles below roughly 400px of container width. A two-column span needs two tracks to exist, and when only one track fits the browser creates an implicit second track that can overflow the container. Lower the default width, or drop the big and wide modifiers at that size, instead of relying on shrinking.

Token overrides are the intended escape hatch: the module reads width, height, gap, caption colors, and the small and large gap values from custom properties, so a local override on one collage does not affect the rest of the page.

Accessibility

A collage is a set of images, so the meaning lives in the image text rather than in the grid classes.

  • Write a useful alt for every image that carries meaning, and leave alt="" only for tiles that are pure decoration.
  • Put a caption in a real figcaption inside figure.collage-fig, so the text is announced with the image instead of existing only as an overlay.
  • Do not put essential text only inside an image. A caption or a heading next to the collage stays readable at any zoom, in either theme, and without the images.
  • Do not rely on .visible for information. A hover-only caption is unreachable on touch and from the keyboard, which is why the visible variant exists.
  • When a tile is a link, give it an accessible name beyond the picture and keep the global focus ring visible on top of the image.

Class reference

Gap modifiers go on the collage element, item modifiers go on the tile, and caption classes go inside the tile.
