Avatar

An avatar pairs a small profile image with a name, a handle, and optional metadata. The wrapper reserves a fixed square for the image, so rows of avatars line up even when the labels wrap to two lines.

class: .avatar - defined in modules/_avatar.scss

Basic usage

.avatar is a positioned wrapper that reserves --r-avatar-default-size of width, currently 2.5rem, plus 15px of padding and a matching min-height . .avatar-fig is pinned to the top left corner at the same size and crops the image with object-fit: cover .

The label is a bold 14/18 block, so it can be a link or plain text. Wrap the secondary line, such as a handle, in a span to drop it back to normal weight. Hovering the label shifts it from --r-avatar-label-color to --r-avatar-label-hover-color .

Ariana Cole @arianacole
HTML 
<div class="avatar">
    <figure class="avatar-fig rounded">
        <img src="https://picsum.photos/40/40?image=500" alt="" />
    </figure>
    <a href="#" class="avatar-label">
        Ariana Cole
        <span>@arianacole</span>
    </a>
</div>

Small avatar

Add .avatar-small next to .avatar for comment headers and dense lists. It swaps the --r-avatar-small-size token in for the padding, the min-height, and the figure, which is 1.875rem by default.

The label moves down 6px in this variant so its baseline lines up with the smaller image. Only the size changes, so the markup stays the same.

Figure shapes

The figure carries the shape, not the wrapper. .rounded clips the image with --r-img-radius and .rounded-circle clips it to a circle. Both add overflow: hidden , so the crop follows the shape.

Leaving both classes off keeps square corners. Mixing shapes in one list looks inconsistent, so pick one per surface.

Metadata blocks

.avatar-primary-block sits directly under the label for inline metadata such as a status and a follower count. It uses 14/18 type and adds a 5px right margin between its children, so a span and two links read as one row.

.avatar-secondary-block holds quieter text underneath, for example a last-seen timestamp. It adds 5px of top padding and reuses the shared small and dimmed text patterns.

Accessibility

The avatar is a small composite, so the work is in naming the image and the link once, not twice.

  • Set alt="" on the image when the .avatar-label already names the person, as in the demos above. A descriptive alt is only needed when the picture is the only label.
  • Keep the person's name as the first text in the label and the handle in the span so screen readers announce them in that order. The visual weight difference is not announced.
  • .avatar-fig is absolutely positioned, so the wrapper's padding and min-height are what hold the space. Do not override them on a smaller parent or the label will overlap the image.
  • In the metadata block the links are read in sequence. Keep each link self descriptive, for example "22k followers" rather than "followers", so it makes sense out of context.
  • The secondary block is ordinary text. Put state such as "Last seen" in the DOM rather than in a pseudo-element, and note that dimmed text still needs to meet contrast requirements for the surface behind it.
  • The label is an a element and picks up the base :focus-visible outline. Do not remove it, and do not add a second focusable element for the image.

Class reference

Sizes and label colors come from the --r-avatar-* tokens. The figure shape classes are shared with the image module.

Class Applies Notes
.avatar Wrapper Reserves the default size plus 15px of left space and sets min-height.
.avatar-small Modifier on .avatar Uses the small token for padding, min-height, and the figure.
.avatar-fig Figure Absolutely positioned top-left box that crops the image to fill it.
.avatar-label Link or text Bold 14/18 block with a hover color; an inner span returns to normal weight.
.avatar-primary-block Metadata row 14/18 type with a 5px right margin between children.
.avatar-secondary-block Secondary row 5px top padding, small and dimmed text.
.rounded Figure modifier Clips the image with the token radius and hides the overflow.
.rounded-circle Figure modifier Clips the image to a circle and hides the overflow.
