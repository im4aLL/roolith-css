Nav

Nav is a flex row of links for moving between views, sections, or sibling pages. It ships horizontal and vertical layouts, center and right alignment, an icon-only mode, and color modifiers for links that should read as actions rather than navigation.

class: .nav - defined in modules/_nav.scss

Basic usage

The list element carries .nav and each row is a .nav-item holding a .nav-link . The link is a block with 7px of vertical padding and the --r-nav-spacing token on each side, which is 13px by default.

.nav pulls itself left by that same spacing so the first label lines up with the edge of the container instead of starting at its own padding. The list is a wrapping flex row, so it reports its own height and needs no .clearfix . The demo wrappers on this page exist only to give the list a full-width surface and are not part of the component markup.

Active and dimmed links

.active belongs on the .nav-item , not on the link. The link reads the active color token through the parent, so one class switches the whole row, and hover reuses the same token.

.dimmed goes on the .nav-link and uses the dimmed link token, which is faint text in light mode and muted text in dark mode. Both states are color only: no border, no underline, no weight change.

<ul class="nav">

</ul>

Primary nav

.nav-primary turns the row into a segmented control: every link gets the nav border radius, and the active link is filled with --r-nav-primary-color and the accent on-color. Inactive links stay text only, so the block does not look like a row of buttons until one is selected.

Centered and right aligned

.nav-center centers the items with justify-content and resets the negative left margin from .nav , so the row is centered on the container without an offset.

.nav-right pushes the items to the end, clears the left offset, and applies the negative spacing on the right instead, so the last label ends flush with the container edge. The two classes are not combined: pick one per list.

Vertical nav

.nav-vertical switches the row to a flex column, stretches the items to the full width, removes the negative margin, adds 5px of bottom padding per item, and zeroes the padding on the last item. Constrain the parent when you need a fixed column width.

Icon-only nav

.nav-icon-only raises the link font size from 14px to 16px so an icon font glyph scales up. It changes nothing else: padding, spacing, and hover stay the same. Inline SVG with its own width and height ignores the font size, which is why the demo icons render at 16px either way.

The framework does not ship an icon set. The SVGs below use currentColor stroke, so they follow the link color and the active color without extra rules.

Colored links

Every palette name produces a .nav-link-{name} class. The link takes the palette fill and its on-color, and hover darkens the fill by 5% and applies --r-button-hover-shadow-dark , so a colored link reads as a button inside the row.

These classes are for actions that sit beside navigation, such as Sign in or Create account, not for marking the current page. Use .active for state and keep color for meaning.

In a header

The layout header is the most common home for a nav. .layout-header-nav pushes the list to the end of the header cell with margin-left: auto , switches it to inline-flex , and hides it below 640px. It also repoints --r-nav-link-color at the header nav token, so the same links match the header surface.

Keep the search form and the nav as siblings inside .layout-header-secondary . The header cell already sets the 20px gap and removes the field margin, so nothing else is needed.

Accessibility

The component is a list of links, so keep the list and wrap it in a landmark when it is a set of navigation links. Name the landmark, and expose the current page as state rather than color.

  • Wrap the list in <nav> with an aria-label that says what the set is for, such as Documentation or Account sections. The framework class does not add a landmark on its own.
  • Put aria-current="page" on the active link, next to .active on the item. The color alone is not announced and disappears for users who cannot see the difference.
  • Do not use .dimmed to mean unavailable. Use it for secondary emphasis; if a link is truly disabled, render it as text instead of an anchor.
  • Icon-only links need an accessible name. Use aria-label on the link and aria-hidden="true" on the icon so the name is announced once.
  • Keep focus visible. The component never removes the outline, and the hover color is not a substitute for it.

Class reference

Layout classes go on the list, state classes go on the item or the link. Colors, spacing, and radius come from the nav token group, so an override on --r-nav-spacing or --r-nav-primary-color moves most of the component. The 7px vertical padding and the link font sizes are fixed rem values.

Class Applies Notes
.nav Base Wrapping flex row that pulls left by --r-nav-spacing , so the first label aligns with the container edge.
.nav-item Row Flex item that keeps its intrinsic width. Holds the active state for the link inside it.
.nav-link Link Block link with 7px vertical padding, 13px horizontal spacing, 14px text, and a color transition.
.active State On the item. Switches the link to the active color token.
.dimmed State On the link. Uses the dimmed link token.
.nav-primary Variant Adds the nav radius to links and fills the active link with the accent color.
.nav-center Alignment Centers the items and resets the negative left margin.
.nav-right Alignment Aligns the items to the end and moves the negative spacing to the right edge.
.nav-vertical Variant Stacks the items in a flex column with 5px bottom padding, last child zeroed.
.nav-icon-only Variant Raises the link font size to 16px for icon glyphs.
.nav-link-primary Color One per palette name: secondary, tertiary, info, success, warning, danger, link, dark, black, white, light.
.layout-header-nav Composition On the list inside a header. Pushes the list to the end of the cell, repoints the link color token, and hides below 640px.
