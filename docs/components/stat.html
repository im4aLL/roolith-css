Stat

A stat shows one number with a label above it and optional context below. The component is text only: it owns the type sizes and the vertical rhythm, and leaves the surface, border, and radius to whatever container you place it in.

class: .stat - defined in modules/_stat.scss

Basic usage

The module defines one wrapper and three slots. .stat centers its text and pads 15px above and below with no horizontal padding, .stat-header is the 12px muted label, .stat-body is the 32px bold value, and .stat-footer is the 12px closing line.

There is no .stat-label or .stat-value class. The label is the header and the value is the body, which keeps the element order in the markup the same as the visual order.

Tweets 55,654 Last updated 23 min ago
HTML 
<div class="stat">
    <span class="stat-header">Tweets</span>
    <span class="stat-body">55,654</span>
    <span class="stat-footer">Last updated 23 min ago</span>
</div>

All three slots are block elements, so they stack without any wrapper per line. The header carries 7px of bottom padding, the footer 10px of top padding, and the body sits between them at the bold weight from --r-global-font-bold-weight.

Stat cards in a grid

Stats are usually shown as a row of cards. Put a .stat inside a .card for the raised surface and the radius, then place the cards in a .row with .columns spans. .medium-6 gives two cards per row on tablet widths and .large-3 gives four on desktop widths, while the default span keeps a single column on phones.

The card keeps its own 20px bottom margin, so set it to zero inside a grid cell where the row gap already separates the cards.

Revenue $48.2k Rolling 30 days
Active users 12,480 Rolling 30 days
Churn 1.8% 0.4 pts
Open tickets 37 12 escalated

            </div>
        </div>
    </div>
    <div class="columns medium-6 large-3">
        <div class="card">
            <div class="stat">
                <span class="stat-header">Active users</span>
                <span class="stat-body">12,480</span>
                <span class="stat-footer">Rolling 30 days</span>

        </div>

For a strip of stats without card surfaces, the block layer has .block-stat with .block-stat-item, .block-stat-label, .block-stat-value, and .block-stat-indicator. It lays the items out in a row from 640px up and is covered on the Blocks side of the docs.

Indicators

The indicator module adds a change marker as a 14px inline element with a masked arrow in front of it. is-upward paints it with --r-indicator-upward-color, is-downward with --r-indicator-downward-color, and is-flat with --r-indicator-flat-color. There is also is-online for a filled dot.

Place the indicator in the footer for a comparison against the previous period, or in the header next to the label when the change describes the number itself. The indicator sets its own 14px font size, so it reads slightly larger than the 12px slot it usually sits in.

Monthly revenue $48,290 12.4% vs last month
Refunds $1,120 0.0% vs last month
Queue depth 4 All workers healthy
HTML 
<div class="stat">
    <span class="stat-header">Monthly revenue</span>
    <span class="stat-body">$48,290</span>
    <span class="stat-footer">
        <span class="indicator is-upward">12.4%</span>
        vs last month
    </span>
</div>

<div class="stat">
    <span class="stat-header">Refunds</span>
    <span class="stat-body">$1,120</span>
    <span class="stat-footer">
        <span class="indicator is-flat">0.0%</span>
        vs last month
    </span>
</div>

The arrow is a mask painted with the indicator color, so it follows the modifier without an icon font. Pair the color with the sign or the word you already write, because color alone does not carry the direction for every reader.

Containers and alignment

The stat has no background, border, or radius, so it works inside a card, a box, or a page section that already draws one. A .box gives a flatter surface with a single border when cards feel too heavy for a dashboard.

The center alignment comes from the module layer, which is loaded after the typography utilities, so .text-left on the same element does not win. Set text-align: left inline or in a later rule of your own when a stat has to sit against a chart axis.

Uptime 99.98% Last 90 days
P95 latency 184 ms Last 24 hours
HTML 
<div class="box">
    <div class="box-body">
        <div class="stat">
            <span class="stat-header">Uptime</span>
            <span class="stat-body">99.98%</span>
            <span class="stat-footer">Last 90 days</span>
        </div>
    </div>
</div>

<div class="box">
    <div class="box-body">
        <div class="stat" style="text-align: left">
            <span class="stat-header">P95 latency</span>
            <span class="stat-body">184 ms</span>
            <span class="stat-footer">Last 24 hours</span>
        </div>
    </div>
</div>

Accessibility

A stat is a number with a label, and the markup order is what makes it readable out loud.

  • Pair every number with a visible label. The .stat-header text is the label, and a bare 32px figure carries no meaning on its own.
  • The arrow is a ::before pseudo-element, so it produces no text for assistive technology. Write the direction into the label, as in up 12.4% or down 2%, instead of leaving it to the glyph.
  • Do not rely on the indicator color alone for a direction. Upward maps to success and downward to danger out of the box, which can be backwards for a metric where a rise is bad.
  • Keep heading order. Place the stat inside a section that already has a real heading, and do not promote the number to a heading level to size it.
  • Keep the label, the value, and the footer in that order in the markup. The module styles the slots, so the reading order has to follow the visual order.

Class reference

Four classes, no component tokens. Colors come from the shared text tokens, so both themes follow automatically.

Class Applies Notes
.stat Wrapper Centered text with 15px of vertical padding. No surface, border, or radius.
.stat-header Label 12px block in --r-text-muted with 7px below it.
.stat-body Value 32px block at --r-global-font-bold-weight.
.stat-footer Footer 12px block in --r-text-subtle with 10px above it.
.indicator Composition 14px inline change marker with a masked arrow. Modifiers: is-upward, is-downward, is-flat, is-online.
