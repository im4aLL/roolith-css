Action menu

An action menu collects the actions that apply to one record, panel, or block header. The list lays out vertically on small screens and switches to a horizontal row from 640px up, so the same markup fits a narrow table row and a wide toolbar.

class: .action-menu-list - defined in modules/_action-menu.scss

Basic usage

The .action-menu root carries variant classes but declares no styles of its own. Layout lives on .action-menu-list, which is a flex column with a --r-action-menu-list-gap gap and turns into a row at the medium-up breakpoint of 640px.

Each .action-menu-link is a padded flex row with an 8px gap, a 14px label, the token radius, and hover styles that swap the muted text for the accent color over --r-surface-muted. Its resting background is --r-action-menu-item-background, which is var(--r-surface) in light mode and transparent in dark mode.

Icons

Drop an icon inside the link next to .action-menu-label and give it .action-menu-icon. The link is already a flex row, so the 8px gap spaces the icon from the text.

The framework does not ship an icon set. The repository root demos, index.html and admin.html, load Iconoir and use classes such as iconoir-settings, which works because the link is a flex row and the icon inherits its font size. The example below uses inline SVG with currentColor so it renders without any extra stylesheet and inherits the link color on hover.

Primary variant

Add .action-menu-primary to the .action-menu root to turn the links into stacked, centered tiles. The link becomes a column, is capped at 150px wide, and centers its text; the icon is sized from the .action-menu-icon font size of 18px.

Inline SVG does not read font size, so set width and height to 18 on the SVG in this variant. The icons below do exactly that.

Highlight item

Add .action-menu-item-highlight to an .action-menu-item to mark it with a 5px dot in the top right corner. The dot is painted with var(--r-accent) by the item's ::before pseudo-element, and it is positioned against the item's position: relative, so the modifier only works on the list item.

A single dot carries no meaning on its own. Use it for a secondary cue, such as "this action destroys data", and keep the meaning in the label.

Accessibility

The component is a list of controls, so the semantics come from the elements you choose inside it.

  • Wrap the list in <nav> with an aria-label that names the group, because a page can hold several action menus. A <ul> keeps the item count available to screen readers.
  • Use <a> for navigation and <button type="button"> for commands. The .action-menu-link class works on both.
  • The highlight dot is a ::before pseudo-element, so it has no text alternative. Pair it with a label that states the consequence, for example "Delete", rather than relying on the dot.
  • .action-menu-label sets user-select: none. Keep it to the action name and do not put text there that users need to copy.
  • In the primary variant the link is capped at 150px and labels wrap rather than truncate. Keep labels to one or two words so the tiles stay even.
  • Focus outlines come from the base layer, which draws a 2px :focus-visible ring on links and buttons. Leave it in place.

Class reference

The root carries the variant, the list owns layout, and the link owns the visual treatment. Spacing and colors come from the --r-action-menu-* tokens.

Class Applies Notes
.action-menu Root No declarations of its own. Carries the primary modifier.
.action-menu-primary Root modifier Stacks icon over label, centers text, caps links at 150px.
.action-menu-list List Flex column with the token gap; a row from 640px up.
.action-menu-item List item Relative positioning context for the highlight dot.
.action-menu-item-highlight List item modifier Adds the 5px accent dot in the top right corner.
.action-menu-link Link or button Padded flex row, 14px text, hover accent and muted surface.
.action-menu-icon Icon element Sits in the link's flex row. Font size is 18px in the primary variant.
.action-menu-label Label span Holds the action name and disables text selection.
