Why roolith

Everything you need, nothing you have to fight

A focused foundation for real projects: sensible defaults out of the box, and an override point for every decision you want to make your own.

Token driven

Every color, radius, shadow, and spacing step flows from CSS custom properties you can override anywhere in your cascade.

Dark mode built in

Add one class and the whole system re-tunes itself. No parallel stylesheet, no duplicated component rules.

Responsive by default

Fluid type, mobile-first breakpoints, and a flexible 12 column grid that collapses cleanly at every viewport.

Modern CSS foundation

Built on color-mix(), custom properties, and progressive enhancement with sensible fallbacks where they matter.

Component ready

Buttons, forms, tables, cards, navigation, and more - all sharing the same token layer so they stay in sync.

No JS required

Everything renders and themes with plain HTML and CSS. Scripts stay optional, so your bundle stays small.

Palette

One palette, every surface

Core colors map to semantic tokens, so components reference intent instead of raw values. Swap the primitives and the entire interface follows.
